     SOP ARCHITECTURE 09


   Setup and Tracking Flow (GSC, GA4, GTM,
   Clarity, Bing)
   Pehla tracking, pachhi growth.


Every new site needs these connected on day 1. For an existing site, check each one. Folder: 07 Setup and
Tracking. Use one Google account for all three and write it in the access list.
How to read: go top to bottom, one box at a time. Click a blue link to open that SOP.   NEW SITE   only for a new site.
 EXISTING SITE only for an old site. BOTH do it always.
