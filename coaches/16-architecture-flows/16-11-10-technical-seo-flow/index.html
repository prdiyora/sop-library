     SOP ARCHITECTURE 10


   Technical SEO Flow
   Google ne site vanchva ma problem na pade.


Find and fix what stops Google from reading and indexing. Folder: 08 Technical SEO. Fix by priority and
log every change.
How to read: go top to bottom, one box at a time. Click a blue link to open that SOP.   NEW SITE   only for a new site.
 EXISTING SITE only for an old site. BOTH do it always.


           Crawl the site       BOTH
     1
           Run Screaming Frog (free to 500 URLs). Save the issue list.
            08 Technical / 06 Technical SEO Audit (Screaming Frog Crawl)

           Done when: Crawl export saved.

                                                              ↓
     2     Check indexing         BOTH
           GSC, Indexing, Pages. Read the not-indexed reasons. Use URL Inspection on key pages.
            08 Technical / 01 Indexing Check (GSC Page Indexing)

           Done when: Key pages are indexed.

                                                              ↓
           Fix canonical, duplicates and noindex                  BOTH
     3
           One main URL per page. Remove accidental noindex.
            08 Technical / 02 Canonical, Duplicate Content & Noindex

           Done when: No important page has noindex.

                                                              ↓
           Fix redirects and broken links             BOTH
     4
           301 for moved pages, no chains, fix internal 404s.
            08 Technical / 03 Redirects, 404 & Broken Links

           Done when: No 4xx or 5xx on key pages.

                                                              ↓
           Add schema         BOTH
     5
           Organization, WebSite, Breadcrumb, Product or Article as needed.
            08 Technical / 04 Schema Markup (Structured Data)

           Done when: Rich Results Test passes.

                                                              ↓

            Fix images       BOTH
     6
            Rename, compress, alt text, correct sizes.
             08 Technical / 05 Image SEO & Alt Text

            Done when: Images are under 200 KB where possible.

                                                                ↓
            Check crawl budget and JavaScript                   BOTH
     7
            Only for big or JS sites. Check the rendered HTML in URL Inspection.
             08 Technical / 08 Crawl Budget, Log Files & JavaScript SEO
            Done when: Key content shows in rendered HTML.

                                                                ↓
            International (USA and UK)               BOTH
     8
            Add hreflang if there are separate versions.
             08 Technical / 09 International SEO & hreflang (USA + UK)

            Done when: hreflang has return links.

                                                                ↓
            Redesign or platform move                EXISTING SITE
     9
            Do the redirect map before launch. Never skip this.
             08 Technical / 07 Website Redesign & Migration SEO

            Done when: Every old URL maps to a new one.

                                                                ↓
    10      Log and re-check           BOTH
            Write the date and the change. Check again after 4 to 6 weeks.
             08 Technical / 06 Technical SEO Audit (Screaming Frog Crawl)

             10 Reporting and Maintenance / 04 SEO Maintenance Routine (Weekly / Monthly / Quarterly)

            Done when: Fix log is updated.
