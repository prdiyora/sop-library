📈 11.6 — Looker Studio Traffic Dashboard — Build Guide (Report 4)

Dabbo 11 · Client Reporting System · ✅ Done

Goal: client ane team ek najar ma joi shake ke traffic kyathi (channel/source), ketlo, kya thi (country/device), kaya pages par ane ketla goals ma convert thay chhe. Setup basics pan aa j doc ma chhe (juno 07 → 03 doc merge thayo).

Ek var banavo, pachhi copy Pehla ek client mate puro dashboard banavo = Master Template. Navo client: report → ⋮ → Make a copy → navi copy ma data sources badlo (GA4 property, GSC property, tracking sheet). 10 minute ma navo dashboard taiyar.

11.6.C 3. Pages ane charts (aa j order ma banavo)

Page 1 — Overview (client mate sauthi important)

  • Header bar: client logo + naam + "Organic SEO Dashboard" + Date range control (default: Last 28 days, comparison: Previous period).
  • Scorecards (GA4, filter Organic Search): Organic Sessions · Organic Users · Key events · Revenue — dar ek ma comparison arrow.
  • Scorecards (GSC Site): Clicks · Impressions · CTR · Avg Position (position mate "lower is better" — comparison color ulto set karo).
  • Time series: GSC Clicks + Impressions (2 axis), last 90 days.
  • Time series: GA4 Sessions by Session default channel group (stacked) — badha channels.

Page 2 — Traffic kyathi aave chhe (Channels & Sources)

  • Donut: Traffic Source Group (calculated) → Sessions.
  • Table: Session source / medium → Sessions, Users, Engagement rate, Key events, Revenue (sort Sessions).
  • Bar (stacked by month): Month × Session default channel group → Sessions.
  • Table — Referral sites: filter Channel = Referral → Session source, Sessions, Key events. (Backlink/listing ma thi kharekhar traffic aave chhe ke nahi te dekhay.)
  • Scorecard
  • table — AI Assistants: filter Traffic Source Group = AI Assistants → source, sessions, landing page.

Page 3 — Kya thi (Country, City, Device)

  • Geo map: Country → Sessions (GA4, Organic).
  • Table: Country, City → Sessions, Key events.
  • Pie: Device category → Sessions.
  • Table (GSC Site): Country → Clicks, Impressions, CTR, Position — target market (e.g. USA/UK) mathi j traffic aave chhe ke nahi.

Page 4 — Landing pages (kaya page par traffic)

  • Bar: Page Type (calculated) → Organic Sessions.
  • Table (GA4, Organic): Landing page → Sessions, Engagement rate, Key events, Revenue. Heatmap on Sessions.
  • Table (GSC URL Impression): Landing Page → Clicks, Impressions, CTR, Avg position. Filter control: Page Type.
  • Low CTR filter: Impressions ≥ 300 ane CTR < 1% — rewrite candidates (Report 3 sathe match).

Page 5 — Keywords (GSC)

  • Filter controls: Branded vs Non-branded, Position Band, Country, Device.
  • Bar: Position Band → number of queries (Record Count) ane Clicks.
  • Table: Query → Clicks, Impressions, CTR, Avg position (sort Impressions).
  • Table — Striking distance: filter Position 8–20 ane Impressions ≥ 20, Non-branded.

Page 6 — Goals & Conversions

  • Table: Event name → Key events (GA4), filter Organic Search.
  • Bar: Session default channel group → Key events + Revenue (SEO vs Ads vs Social compare).
  • Combo chart (Google Sheet): Month → Target clicks vs Actual clicks + Achievement % (Report 1 "Monthly Goal" tab).
  • Scorecards (Sheet): Authority Score, Referring Domains, DA — chhello mahino.

11.6.D 4. Design rules (attractive + saaf)

  • Theme: Theme and layout → Extract theme from image (client logo) → brand colors. Background white/light, 1 primary + 1 accent color.
  • Layout: upar header bar (logo + date control) badha pages par same — header select → "Make report-level".
  • Scorecards: 4 per row, same size, compact numbers (12.5K), comparison arrow chalu.
  • Charts: page par 6–8 thi vadhu nahi. Dar chart nu title prashna jevu: "Traffic kyathi aave chhe?"
  • Navigation: Page navigation left side (tabs). Page naam: Overview · Sources · Location · Pages · Keywords · Goals.
  • Text box: Overview par niche 2–3 line "Is mahine shu thayu" — dar mahine update.
  • Number format: CTR %, revenue currency, position 1 decimal.
  • Mobile: View mode ma phone par check karo.

11.6.E 5. Sharing ane schedule

  • Share → client email → Viewer (Editor kyarey nahi).
  • Share → Schedule email delivery → dar mahine 3 tarikh → PDF client + manager ne.
  • Report settings ma data freshness (GA4 ~12 hours) — "Data last updated" text box muko.
