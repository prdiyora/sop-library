📈 11.5 — SEO Live Report — Universal SOP (koi pan client / project mate)

Dabbo 11 · Client Reporting System · ✅ Done

Aa SOP ma Client A Products no report jem banavyo, e j flow step-by-step lakhyo chhe. Navo client hoy to aa j order ma follow karo: Setup → Data → Analysis → Content → Build → QA → Deploy.

11.5.B 1. Golden rules (kyarey todvana nahi)

  1. Ek pan number banavvano nahi. Darek number GSC ke GA4 mathi j aavvo joie. Dummy/demo data hoy to page par upar mota akshar ma "DEMO DATA" lakho.
  2. Saachu account check karo. Composio / Chrome je Google account thi connected chhe ema client ni property chhe ke nahi, e pehla check karo (Client A vakhte connected account ma Client A j na hatu).
  3. $0 revenue hoy to saachu batavo. Revenue 0 hoy to "tracking set nathi" e Fix tarike lakho, khota orders na mukvana.
  4. Period hamesha lakho. Darek table/section ma date range ane comparison range lakho.
  5. Brand keywords alag. Branded ane Non-branded keyword ne mix na karvana.
  6. Content (rewrites/ideas/fixes) ma darek suggestion sathe "Why (data)" reason — impressions, position, CTR na number sathe.

11.5.E 4. Step 3 — GSC data levo

Option A: Composio thi (automatic, live website mate)

  1. Composio ma google_search_console connect karo — je Google account ma client ni property chhe e j account thi.
  2. GOOGLE_SEARCH_CONSOLE_LIST_SITES chalavo → client ni property list ma chhe ke nahi e check karo. Na hoy to navu account connect karo.
  3. GOOGLE_SEARCH_CONSOLE_SEARCH_ANALYTICS_QUERY darek period mate 2 var (current + comparison):

{ "site_url": "https://client.com/", "start_date": "2026-10-06", "end_date": "2026-11-02", "dimensions": ["page"], "row_limit": 1000 }

dimensions ma ["page"], ["query"], ane trend mate ["date"] — ek ek alag call. Note: ctr 0–1 fraction ma aave chhe, display vakhte ×100 karo.

Option B: Chrome browser thi (Composio na hoy tyare — Client A ma aa j vapryu)

  1. Aa URL kholo (resource_id, dates, breakdown badlo):

https://search.google.com/search-console/performance/search-analytics?resource\_id=https%3A%2F%2Fclient.com%2F\&start\_date=20261006\&end\_date=20261102\&compare\_start\_date=20260908\&compare\_end\_date=20261005\&metrics=CLICKS%2CIMPRESSIONS%2CCTR%2CPOSITION\&breakdown=page

breakdown=page → pages, breakdown=query → keywords.

  1. Page khulya pachhi console/JS ma aa extractor chalavo. Ek var FX localStorage ma save karo, pachhi darek page par await eval(localStorage.getItem('FX'))('p28') chalavo:

// Columns: [url/query, clicks, prevClicks, impr, prevImpr, pos, prevPos] (async k=>{ await new Promise(r=>setTimeout(r,3500)); const n=s=>+String(s).replace(/,/g,'').replace('%','')||0; const T=[...document.querySelector('table').rows].slice(1).map(r=>[...r.cells].map(c=>c.innerText.trim())); const b=document.body.innerText; const tot=[...b.matchAll(/(Total clicks|Total impressions|Average CTR|Average position)\n([\d,.K%]+)\n[^\n]*\n([\d,.K%]+)/g)].map(m=>[m[2],m[3]]); localStorage.setItem('R_'+k, JSON.stringify({tot, rows:T.map(c=>[ c[0].replace('https://client.com','').split('?')\[0\].split('\#')\[0\] .replace(' Copy URL to clipboard Open in new tab Inspect URL',''), n(c[1]),n(c[2]),n(c[4]),n(c[5]),n(c[10]),n(c[11]) ]).sort((a,b)=>b[3]-a[3]).slice(0,80)})); return 'ok '+T.length+' '+JSON.stringify(tot); })

Keys: p7 q7 p28 q28 p90 q90 (p = pages, q = queries).

  1. Badho data ek sathe kadhva (JS output 1000 characters par cut thay chhe, etle page par lakhi ne vancho):

const o={};['p7','q7','p28','q28','p90','q90'].forEach(k=>o[k]=JSON.parse(localStorage.getItem('R_'+k))); const p=document.createElement('pre');p.textContent=JSON.stringify(o);document.body.replaceChildren(p);

Pachhi get_page_text thi akho JSON vanchi ne data.json ma save karo.

Dhyan:

  • Compare mode ma column order: 0 page | 1 clicks | 2 prevClicks | 3 diff | 4 impr | 5 prevImpr | 6 diff | 7 ctr | 8 prevCtr | 9 diff | 10 pos | 11 prevPos | 12 diff.
  • #anchor vala duplicate URLs aave chhe → dedupe karo (pehli row rakho).
  • Totals "65K" jem rounded aave chhe — e j rite batavo, "approx" lakho.

11.5.F 5. Step 4 — GA4 data levo

Option A: Composio

GOOGLE_ANALYTICS_LIST_ACCOUNT_SUMMARIES → property check. Pachhi GOOGLE_ANALYTICS_RUN_REPORT:

{ "property": "properties/558018808", "dateRanges": [{"startDate":"2026-10-06","endDate":"2026-11-02"}], "dimensions": [{"name":"landingPage"}], "metrics": [{"name":"sessions"},{"name":"activeUsers"},{"name":"transactions"},{"name":"purchaseRevenue"}], "dimensionFilter": {"filter":{"fieldName":"sessionDefaultChannelGroup","stringFilter":{"value":"Organic Search"}}}, "limit": 500 }

metricValues[].value string aave chhe → number ma convert karo.

Option B: Chrome

  1. GA4 → property picker → client select.
  2. Reports → Engagement → Landing page.
  3. Add filter → Dimension: Session default channel group → exactly matches → Organic Search → Apply.
  4. Date range set karo, rows per page 25/50.
  5. get_page_text thi table vancho: Landing page, Sessions, Active users, Engagement time, Key events, Total revenue.

Check karo: Total revenue ane Key events 0 hoy to → ecommerce tracking set nathi. Report ma "Orders/Revenue: 0 — tracking not set up" lakho ane Fixes ma High priority.

11.5.I 8. Step 7 — Content sections (rewrites, ideas, fixes)

8.1 Page rewrites for this week (3 pages)

Kai page pasand karvi:

  1. High impressions + CTR < 1% + position 4–20 → FULL PAGE REWRITE
  2. Impressions vadhya pan position ghati (Google navi queries test kare chhe) → SEO-FOCUSED REWRITE
  3. Topic ni queries position 30+ par (topic own nathi kartu) → SEO-FOCUSED REWRITE + collection ↔︎ blog link

Darek rewrite ma:

  • Why (data): impressions, clicks, CTR, position, top queries numbers sathe
  • Full rewrite: Title (≤60), Meta (≤155), H1, akhi body (H2/H3 outline + text), FAQ (4 q), internal links, schema
  • SEO-focused rewrite: fakt badlav — title/meta, intro ma exact query, nava H2 (missing queries mathi), tables, FAQ, internal links

Example (Client A): /collections/porcelain-sinks — 3,471 impr, 17 clicks (0.5% CTR), pos 10.1; meta ma fakt bathroom, pan "porcelain kitchen sink" queries aave chhe → full rewrite.

8.2 New blog topics & collection ideas (90-day data)

Blog topic mate signal:

  • Question type query, position 1–10, pan dedicated page nathi (e.g. "why diamond segments wear too fast…" pos 3.7)
  • Navi query je jaldi vadhti hoy (15 → 157 impr)
  • Product/collection position 20+ — support blog thi help mle

Collection idea mate signal:

  • Ek j intent ni ghani queries (kitchen porcelain sink, white porcelain kitchen sink…) ane emne match karti collection nathi
  • Brand/product family queries (tenax proseal 767 impr) — dedicated collection nathi

Darek idea sathe: title, target keyword, supporting keywords, reason with numbers, slug, outline / products.

8.3 Fixes spotted on the site

Table format: Priority | Page | Problem | Reason | Fix / rewrite (exact navo title/meta/alt/H1 lakho, fakt "fix karo" nahi).

  6. Keyword positions — 2 tabs: Non-branded / Branded, "Search ↗" Google link (&gl=us&hl=en)

  • SEO-focused)

11.5.L 11. Step 10 — QA checklist (publish pehla)

  • Darek number source sathe match (GSC/GA4 ma 3–4 random numbers cross-check)
  • Koi demo/dummy data nathi (ke chhe to clearly label)
  • Period labels badha sections ma saacha
  • Duplicate (#anchor) URLs dedupe thai gaya
  • Branded keywords non-branded tab ma nathi
  • GA4 revenue 0 hoy to clearly lakhyu chhe
  • Darek rewrite/idea/fix ma "why" + number chhe
  • Mobile width (≈375px) par horizontal scroll nathi
  • noindex, nofollow meta chhe
  • Links client ni site par saacha khule chhe
  • Dark mode ma text vanchay chhe

11.5.M 12. Step 11 — Deploy (GitHub → Vercel)

  1. GitHub → New private repo (e.g. client-seo-report).
  2. ZIP extract karo → files upload karo (ZIP nahi). node_modules ane .next na mukvana.
  3. Vercel → Continue with GitHub → Add New Project → repo Import.
  4. Framework: Next.js (auto) → Environment Variables ma section 10.1 ni badhi values.
  5. Deploy → *.vercel.app link client ne mokalo.
  6. Pachhi koi badlav: GitHub ma file update → Vercel automatic redeploy.

Note: repo private chhe pan live link jene male e joi shake. noindex thi Google ma nahi aave. Client data chhe etle REPORT_PASSWORD (ke Vercel password protection) jaruri add karo.
