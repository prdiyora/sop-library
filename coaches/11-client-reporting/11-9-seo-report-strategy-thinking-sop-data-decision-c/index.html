11.9.A PART A — Akho process 1 page ma

1. Client ne samjo        → shu vechay chhe, paisa kya thi aave chhe, brand naam shu chhe
2. Data lo (3 period)     → GSC pages + queries (7 / 28 / 90 days, comparison sathe), GA4 Organic
3. Data ne 6 sawal pucho  → (PART C) — darek sawal ek report section banave chhe
4. Pages pasand karo      → Rewrite (3), New blog (5–8), New collection (3–5), Fix (8–10)
5. Site live vancho       → top 10 pages: title, meta, H1, alt, schema, content
6. Content lakho          → darek suggestion = "Data reason + Shu badalvu + Exact navu text"
7. Report banavo          → sections ane design (PART F)
8. QA → Deploy            → GitHub → Vercel → client ne link (PART H) ```

Ek line ma strategy: > *Google already je page ne batave chhe (impressions) pan click nathi madta (low CTR / position 8–20), e pages ne pehla sudharo. Google je queries mate tamari site batave chhe pan matching page nathi, e mate navu page banavo.*

Aa line tame yaad rakhsho to badha decisions emathi j nikle chhe.

## PART B — Data lidho kevi rite (Client A example)

| Data | Kya thi | Kem joie |
|---|---|---|
| GSC Pages (clicks, impr, CTR, position, current vs prev) | Search Console → Performance → Pages, compare mode | Kayu page vadhe chhe, ghate chhe, kayu page "chance" chhe |
| GSC Queries | Same → Queries tab | Loko shu search kare chhe; navi queries; position |
| 3 period: 7 / 28 / 90 divas | Date range badli ne | 7d = taja signal, 28d = main report, 90d = trend + nava content ideas |
| GA4 Organic landing pages | GA4 → Engagement → Landing page + filter `Session default channel group = Organic Search` | SEO thi aavela visitors, engagement, orders, revenue |
| Live page audit | Site ni page kholi ne HTML vanchvu | Title/meta/H1/alt/schema ma shu khoti chhe |

Kem 3 period?
- 7 divas: aa week shu thayu. Navi queries jaldi dekhay chhe.
- 28 divas: main report period. Ek mahina ni stable picture aape chhe.
- 90 divas: trend saacho chhe ke nahi e khabar pade (Client A: 904 → 2,420 clicks). Nava blog ke collection na ideas 90 divas na data parthi j aapva, karan ke tyare j data puratu hoy chhe.

## PART C — Data ne 6 sawal (aa j "mind" chhe)

Data aavya pachhi seedha report na banavo. Pehla aa 6 sawal pucho. Darek sawal no jawab report no ek section bane chhe.

### Sawal 1: "Overall site upar jay chhe ke niche?"
- Clicks, impressions, CTR ane position na totals current vs previous sarkhavo.
- Client A 28d: Clicks 743 → 843 (upar), Impr 68.5K → 65K (thoda niche), CTR 1.1% → 1.3% (upar).
- Matlab: impressions thodi ghati pan clicks vadhya. Etle je traffic aave chhe e vadhu relevant chhe. Aa positive story chhe.
- Rule: Clicks upar ane impr niche hoy to CTR sudharyo chhe. Clicks niche ane impr upar hoy to position ke snippet ni problem chhe.

### Sawal 2: "Kayu content kaam kare chhe?" (Blog vs other pages)
- URL ma `/blogs/` hoy e blog. Baki badhu collection, product, home.
- Client A: top impressions vala pages ma ghana blogs chhe (cutting-metal-with-a-skil-saw 5,711 impr, choose-the-right-blade 3,990). Matlab: blogs traffic laave chhe, pan revenue collections/products thi aave chhe. Etle blog → collection internal link sauthi mahatva nu kaam chhe.

### Sawal 3: "Shu badlayu?" (What changed section)

| Signal | Kevi rite shodhvu | Matlab shu |
|---|---|---|
| Clicks gainers | `clicks − prevClicks` sauthi vadhu | Kaam thayu chhe, client ne batavo |
| Impression gainers | `impr − prevImpr` sauthi vadhu | Google aa page ne navi queries mate test kare chhe. Opportunity |
| New keywords | prev impr = 0, current impr ≥ 5 | Google navo topic tamari site sathe jode chhe. Nava content no idea |
| Position movers | `prevPos − pos` vadhu | Ranking sudhri. Report ma batavo |
| Striking distance | position 8–20, impr ≥ 20 | Page 1 ni najik chhe. Thodu kaam karo to vadhu clicks malse |
| Low CTR | impr ≥ 100–300, CTR < 1% | Google batave chhe pan loko click nathi karta. Title/meta/intent ni problem |

### Sawal 4: "Loko shu search kare chhe?" (Keywords)
- Branded (Client A, Client A stone products): aa loko tamne already jane chhe. Aa SEO nu kaam nathi, brand nu chhe. Alag tab ma rakho.
- Non-branded (akemi, porcelain sink, tenax proseal): aa SEO nu saachu result chhe. Main tab.
- Dhyan: "akemi" ke "tenax" product brand chhe, store brand nathi. Etle e non-branded gane.

### Sawal 5: "SEO thi business ne shu malyu?" (GA4)
- Organic sessions, users, engagement, orders, revenue.
- Client A: 821 organic sessions pan revenue $0, key events 0. Sales nathi thata evu nathi, tracking j nathi.
- Rule: Revenue 0 hoy to pehla tracking check karo. Report ma "tracking not set up" lakho ane Fixes ma High priority aapo. Khota orders kyarey na mukvana.

### Sawal 6: "Shu karvu?" (Action, PART D) Upar na 5 sawal mathi je pages ane queries nikle, emathi Rewrite / New content / Fix nakki karo.

## PART D — Decision tree: Rewrite, New Page, ke Fix?

``` Query/page joyu │ ├─ Page chhe + impressions vadhu + CTR < 1% + position 4–20 │     └─► FULL PAGE REWRITE (title, meta, H1, body, FAQ — badhu navu) │ ├─ Page chhe + impressions vadhya pan position ghati │     └─► SEO-FOCUSED REWRITE (Google navi queries test kare chhe → e queries page ma umero) │ ├─ Page chhe + topic ni queries position 30+ par │     └─► SEO-FOCUSED REWRITE + collection ↔ blog internal links (topic "own" nathi thatu) │ ├─ Query ma impressions chhe pan MATCHING page j nathi │     ├─ Informational query (how, why, what, can, best, vs, guide)  ─► NEW BLOG POST │     └─ Commercial/product query (buy, sinks, blades, sealer, brand + product) ─► NEW COLLECTION │ ├─ Ek j intent ni 3+ queries, ane collection eni sathe match nathi kartu │     └─► NEW COLLECTION (athva hal ni collection ne split karo) │ └─ Page technical rite kharab (alt nathi, 2 H1, meta lambi, schema nathi, tracking nathi) └─► FIX (priority: High / Medium / Low) ```

### Search intent kevi rite olakhvo (simple rule)
| Query ma aa shabd | Intent | Page type |
|---|---|---|
| how, why, what is, can, tips, guide, vs, mistakes | Informational | Blog |
| best, top, review, compare | Commercial research | Blog (comparison) ke collection |
| product naam, brand + product, plural ("sinks", "blades"), price, buy | Transactional | Collection / Product |
| store naam | Navigational (branded) | Homepage |

### Priority kevi rite nakki karvi ``` Priority score ≈ Impressions × (position 4–20 hoy to vadhu) × Business value (product/collection > blog) ```
- Pehla e pages lo je already page 1 ni najik chhe ane paisa vala chhe (collections/products).
- Position 50+ vala pages par pehla kaam na karo. Ema vadhu mehnat lage ane result late aave.

## PART E — Client A report ma darek suggestion kem aapyu (worked examples)

### E1. Rewrite #1: `/collections/porcelain-sinks` → FULL PAGE REWRITE

Me shu joyu (data):
- 28d: 3,471 impressions, fakt 17 clicks → CTR 0.5%, position 10.1
- Top queries: "porcelain sink" 902 impr (pos 9.4), "porcelain kitchen sink" 313 impr (pos 9.8)
- Live audit: meta description ma fakt "bathroom sinks" lakhyu chhe

Thinking:
1. Impressions ghani chhe, etle Google page ne relevant mane chhe.
2. CTR 0.5% chhe, etle loko snippet joi ne click nathi karta.
3. Kem? Searcher "kitchen" sink shodhe chhe pan snippet ma "bathroom" lakhyu chhe. Intent mismatch.
4. Position 10 chhe, etle page 1 nu chhellu sthan. Thodu content sudhre to top 5 ma aavi shake.
5. Aa collection page chhe, etle direct paisa vala page chhe. Sauthi upar priority.

Rewrite ma shu badlyu:
| Element | Juno | Navo | Kem |
|---|---|---|---|
| Title | Porcelain Sink for Kitchen & Bathroom \| Client A | Porcelain Sinks for Kitchen & Bathroom \| Client A | Plural "sinks" = transactional; kitchen pehla |
| Meta | Fakt bathroom | Kitchen + bathroom, in stock, free shipping | Intent match → CTR vadhe |
| H1 | Porcelain Sinks | Porcelain Sinks for Kitchen & Bathroom | Banne intent cover |
| Body | Ochhu ane bathroom-focused | Kitchen ane bathroom na alag H2, comparison table, cleaning, FAQ | Badhi top queries cover |
| Links | — | Blogs ane EZ sink brackets | Topic cluster |
| Schema | Fakt Organization | + FAQPage + BreadcrumbList | Rich result |

### E2. Rewrite #2: `/blogs/news/kitchen-sink-cabinet-combo-buying-guide` → SEO-FOCUSED REWRITE

Data: impressions 365 → 1,203 (3 gana), pan position 7.4 → 11.2 (niche gayu). Navi queries: "kitchen cabinets for sink" (pos 37.2), "kitchen sink with cabinet" (13.5), "kitchen sink and cabinet combo" (10.1). Aa queries pehla na period ma nahotī.

Thinking:
- Impressions vadhya ane position ghati, etle Google aa page ne ghani navi queries mate test kare chhe. Average position niche aave chhe karan ke nava, door na keywords umerata jay chhe.
- Page aakhu kharab nathi, etle full rewrite nathi karvo. Fakt e navi queries ne page ma jagya aapvi chhe.

Shu badlvu (fakt aatlu):
- Title ane meta ma exact phrase "kitchen sink and cabinet combo".
- Intro na pehla 100 words ma "kitchen sink with cabinet".
- Nava H2, darek ek navi query mathi: "Kitchen cabinets for sink: base sizes", "Cheap combo: what to check", "Ready-made vs custom".
- Size table, FAQ, ane collection par link.

Rule: *Navi query = navo H2 section.* Google ne je query mate tame dekhao chho, e query no jawab page ma spasht hovo joie.

### E3. Rewrite #3: Core drill bits (blog + collection) → SEO REWRITE + linking

Data: blog ma 1,684 impr pan fakt 6 clicks, pos 10.6. Collection pos 23.7. "what is a core drill bit" pos 50.3, "core drill bit" pos 37.3. Collection ma 2 H1.

Thinking: topic site par chhe pan Google ene topic no "owner" nathi manto. Blog ane collection ek bija ne support nathi karta, ane collection ma 2 H1 thi signal mix thay chhe.

Shu karyu:
- Blog ma pehlo H2 "What is a core drill bit?" ane 40–50 words ni definition (featured snippet mate).
- Collection ma ek j H1, 150 words nu intro, ane blog par link.
- Blog thi collection par link, anchor "shop diamond core drill bits". Aam blog ane collection ek cluster bane chhe.

### E4. Nava BLOG topics kem aapya

| Topic | Data | Logic |
|---|---|---|
| Why Diamond Segments Wear Too Fast When Cutting Granite | 91 impr, pos 3.7, dedicated page nathi | Google already upar batave chhe, pan saachu jawab aapti page nathi. Dedicated page lakho to click malse |
| How to Choose a Diamond Segment for Marble | 85 impr, pos 3.4 | Upar jevu j, question query chhe |
| Can a Circular Saw Cut Metal Studs? | 36 impr, pos 3, navi query | Top blog (skil saw, 5,711 impr) nu support topic. Cluster majboot thay |
| Best Countertop Protection Film | 292 + 165 impr, pos 21–37 | Product page pos 31 par chhe. Blog bane to e product ne support kare |
| Granite Polishing Pads Grit Sequence | 469 impr, 0 clicks, pos 12.6 | Demand chhe pan saachu content nathi |
| Porcelain vs Stainless Kitchen Sink | 937 + 393 + 125 impr | Comparison intent. Collection ne support kare |
| Akemi Products Guide | "akemi" 10,396 impr | Sauthi moti query chhe, guide thi long-tail pan cover thay |
| Best Sanding Disc for Grinder | 15 → 157 impr (10 gana) | Demand jaldi vadhe chhe |

Blog topic rules (yaad rakho):
1. Question query + position 1–10 + dedicated page nathi → sauthi saro idea (jaldi result).
2. Navi query jeni demand jaldi vadhti hoy (2× thi vadhu) → trend pakdo.
3. Product/collection position 20+ → support blog lakho ane emathi link aapo.
4. Moti head query (akemi 10K) → guide/pillar post.
5. Hamesha 90 divas no data vapro. 7 divas ma noise vadhu hoy chhe.

### E5. Nava COLLECTION ideas kem aapya

| Collection | Data | Logic |
|---|---|---|
| Porcelain Kitchen Sinks | Kitchen-intent porcelain queries 1,600+ impr, pos 10–18 | Hal nu collection bathroom-focused chhe. Intent split karvo |
| Granite Fabrication Tools | granite tools 285 + granite fabrication tools 58 + stone fabrication tools 42 | Ek j intent ni 3 queries ane matching collection nathi |
| Diamond Blades for Granite | 41 + 40 + 39 impr, pos 22.9 | Product intent. Blog (3,990 impr) thi link aapi shakay |
| Tenax Proseal Sealers | tenax proseal 767 + nano 183 | Brand + product family. Dedicated collection nathi |
| Countertop Protection Film | 292 + 165 + 123 impr | Transactional queries pan fakt 1 product page |

Collection idea rules:
1. Ek j buying intent ni 3 ke vadhu queries (plural, product type, brand + product) hoy ane matching collection na hoy → navu collection.
2. Hal nu collection 2 intent mix kare (kitchen + bathroom) ane banne ma impressions hoy → split karo.
3. Brand + product family ni queries 100+ impr hoy → brand sub-collection.
4. Store ma e products hovi joie. Product vagar collection na banavo (thin page thay).
5. Collection ne related blog sathe link karo (cluster).

### E6. Fixes kem shodhya (live audit)

| Fix | Data/Audit | Kem High/Medium/Low |
|---|---|---|
| GA4 tracking | Revenue $0, key events 0 | High: SEO nu business result j map nathi thatu |
| Countertop film product | 88/97 images alt vagar, meta 300+ chars, pos 32.8 | High: product page chhe, image search ane snippet banne kharab |
| Homepage | 84/182 images alt vagar, H1 "More Than Just Tools" | High: homepage nu H1 sauthi mahatva nu signal chhe |
| Blog schema | Fakt Organization schema | Medium: blogs ma sauthi vadhu impressions chhe |
| Collection schema | Fakt Organization schema | Medium |
| Core bits 2 H1 | Audit | Medium |
| Porcelain meta mismatch | Audit + GSC | Medium (rewrite ma cover) |
| Tenax title 67 chars | Audit | Low |
| Akemi title | Audit + CTR 1.1% | Low |
| (not set) landing | GA4 57 sessions | Low |

Fix priority rule:
- High: tracking ke indexing problem, ke paisa vala page par moti problem.
- Medium: template-level (badhi blogs/collections par ek sathe lagu pade) ke page 1 ni najik vala page par.
- Low: cosmetic (title length, nani wording).

## PART F — Report ma shu batavvu, shu nahi (client psychology)

1. Upar positive: clicks, CTR, gainers. Client pehla progress jove.
2. Negative honest pan solution sathe: "Revenue 0" lakho, pan sathe "Fix: tracking setup" pan lakho.
3. Darek number sathe period (Oct 6–Nov 2 vs Sep 8–Oct 5).
4. Darek suggestion = Why + What + Exact text. Fakt "meta sudharo" na lakho, navo meta lakhi ne aapo.
5. Branded alag tab ma. Client ne SEO ni saachi growth dekhay.
6. Google search link (Search ↗) aapo jethi client jate position check kari shake.
7. Report sections no order: Overview → Blog → Other pages → What changed → Keywords → GA4 → Rewrites → Ideas → Fixes.

## PART G — Content kevi rite lakhvu (templates)

### G1. FULL PAGE REWRITE template (collection/category) ``` WHY (data): <impr> impressions, <clicks> clicks (<CTR>%), pos <x>. Top queries: <q1 (impr, pos)>, <q2>. Problem: <intent mismatch / thin content / missing keyword>.

Title (≤60):   <Primary keyword (plural)> for <use 1> & <use 2> | <Brand> Meta (≤155):   Shop <primary kw> for <use>. <Brands/types>, <stock/shipping USP>. <CTA>. H1:            <Primary keyword + main qualifier> Intro (60–100 words): primary kw pehla 1–2 line ma, kone mate, shu malse H2: Why choose <product type>          → 4 bullet benefits H2: <Product type> for <use 1>         → sizes, kevi rite pasand karvu H2: <Product type> for <use 2> H2: <Type A> vs <Type B> vs <Type C>   → comparison table H2: How to care / install              → 2–3 line + blog link H2: FAQ                                → 4 questions (GSC ni question queries mathi) Internal links: 2–3 blogs + 1–2 related collections + 1 accessory product Schema: CollectionPage + BreadcrumbList + FAQPage ```

### G2. SEO-FOCUSED REWRITE checklist (blog)
- [ ] GSC → aa page → Queries: navi queries list karo (prev = 0)
- [ ] Sauthi vadhu impression vali query → title + meta + intro na 100 words
- [ ] Darek mahatvani navi query → ek H2 (exact ke najik nu phrase)
- [ ] Position 4–10 vali question query → H2 niche 40–50 words no direct jawab (snippet)
- [ ] 1 table (size / comparison / steps)
- [ ] FAQ 4 questions + FAQPage schema
- [ ] Pehla section mathi related collection par link (descriptive anchor)
- [ ] "Last updated" date badlo
- [ ] Je bhag kaam kare chhe e na kadho. Fakt umero ane sudharo.

### G3. NEW BLOG BRIEF template ``` Title:              <question ke "how to" format> Slug:               /blogs/news/<short-keyword-slug> Target keyword:     <q> (<impr> impr, pos <x>, 90d) Supporting kws:     <q2>, <q3>, <q4>  (GSC mathi j) Intent:             Informational Why (data):         <reason with numbers> Word count:         1,200–2,000 (top SERP results jetlu) Outline: H1: <title> Intro: 2–3 line ma direct jawab H2: What is / Why <topic> H2: <main steps / types / reasons> (H3 ma breakdown) H2: Common mistakes H2: Tools/products you need  → collection/product links H2: FAQ (4) Internal links IN:  2–3 existing blogs thi aa navi post par link Internal links OUT: 1 collection + 1–2 products Schema:             Article + FAQPage + BreadcrumbList E-E-A-T:            fabricator experience, real photos, author naam ```

### G4. NEW COLLECTION brief template ``` Name:            <product type for use> URL:             /collections/<keyword-slug> Target queries:  <q1 + q2 + q3> = <total impr> Why (data):      <intent group, no matching collection / mixed intent> Products:        <list ke tag/filter rule>  (minimum 6–8 products) Title/Meta/H1:   G1 template mujab Top intro:       60–100 words (products upar dekhava joie) Bottom content:  300–600 words + FAQ Link from:       homepage menu ke parent collection + related blog ```

### G5. ChatGPT / Claude ne content mate prompt ``` You are a senior ecommerce SEO copywriter. Page: <URL> | Type: <collection/blog> GSC data (last 28d): <paste rows: query, impr, clicks, pos> Current title/meta/H1: <paste> Task: <FULL rewrite / SEO-focused rewrite / new blog / new collection> Rules: use ONLY these queries as keywords; title ≤60, meta ≤155; one H1; add H2 for each important new query; FAQ from question queries; suggest internal links to: <list of URLs>; US English; no fake claims or numbers. Output: markdown with Title, Meta, H1, body, FAQ, schema type. ```

## PART H — Report website ne Vercel par deploy karvi

### Option 1: Snapshot report (HTML, aaj na data thi, sauthi saral)
1. Report ni file `index.html` tarike save karo (ek j file, CSS ane JS andar).
2. Navu folder banavo: `client-seo-report-nov-2026/` → emaa `index.html` muko.
3. `<head>` ma `<meta name="robots" content="noindex, nofollow">` umero.
4. GitHub: github.com → New repository → naam aapo → Private → Create → "uploading an existing file" → `index.html` drag kari ne muko → Commit.
5. Vercel: vercel.com → Continue with GitHub → Add New → Project → repo pasand karo → Import.
6. Framework Preset: Other. Build command khali rakho. Output directory pan khali.
7. Deploy → 30 second ma `your-dashboard.vercel.app` link malse.
8. Navo mahino: `index.html` badli ne GitHub par upload karo. Vercel jate redeploy karshe.

### Option 2: Live report (Next.js + Composio + ChatGPT, data jate update)
1. Project ZIP extract karo (`app/`, `lib/`, `package.json`, `.env.example`, `README.md`).
2. GitHub par navo private repo banavo ane badhi files upload karo (ZIP nahi, `node_modules` nahi).
3. Vercel → Import repo → Framework Next.js (auto detect).
4. Environment Variables (Settings → Environment Variables):

| Name | Value |
|---|---|
| `COMPOSIO_API_KEY` | Composio dashboard → API key |
| `COMPOSIO_GSC_ACCOUNT_ID` | Client access vala GSC connection ni ID |
| `COMPOSIO_GA4_ACCOUNT_ID` | Client access vala GA4 connection ni ID |
| `GSC_PROPERTY` | `https://client.com/` ke `sc-domain:client.com` |
| `GA4_PROPERTY_ID` | Number (GA4 URL ma `p` pachhi) |
| `SITE_NAME`, `SITE_URL` | Client naam ane URL |
| `BRAND_TERMS` | `brand,brand name,misspelling` |
| `OPENAI_API_KEY` | ChatGPT key (rewrites/ideas/fixes buttons mate) |

5. Deploy. Error aave to Vercel → Deployments → Logs juo.
6. Navo client = navo Vercel project. Same GitHub repo import karo ane fakt env vars badlo.

Pehla check karo: Composio ma je Google account connected chhe ema client ni GSC/GA4 property dekhay chhe ke nahi (`LIST_SITES` / `LIST_ACCOUNT_SUMMARIES`). Client A ma aa j bhool hati: connected account ma Client A j na hatu.

### Security
- Repo private rakho.
- Vercel link jene male e joi shake. `noindex` thi Google ma nahi aave.
- API keys kyarey code ma na lakho, fakt Vercel env vars ma.

## PART J — Senior SEO ni jem vicharo (yaad rakhva jevu)

- Impressions = Google no vishvas. Clicks = user no vishvas. Impressions chhe pan clicks nathi, etle snippet ke intent ni problem chhe.
- Navi query = Google no hint. Google kahe chhe "aa topic mate tamne test karu chhu". Page ma eno jawab aapo.
- Position 8–20 = sauthi saro ROI. Ochhi mehnat ma vadhu result male.
- Blog traffic laave, collection paisa laave. Banne ne link thi jodo.
- Pehla sudharo, pachhi navu banavo. Hal ni page ne rewrite karvu e navi page karta jaldi result aape.
- Revenue 0 = pehla tracking check karo, SEO ne dosh na aapo.
- Darek suggestion data thi. Data na hoy to suggestion na aapo, athva "hypothesis" lakho.
- Measure karo: rewrite pachhi 2–4 week ma same page na CTR, position ane clicks sarkhavo, ane aavta report ma "Rewrite impact" section umero.
