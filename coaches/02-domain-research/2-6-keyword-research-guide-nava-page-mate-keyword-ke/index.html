🌐 2.6 — Keyword Research Guide — Nava Page mate Keyword kevi rite Pick karvu

Dabbo 02 · Domain Research & Selection · ✅ Done

Updated 19 Nov 2026 — Semrush-first strategy (ChatGPT Plus review thi renew kareli).

2.6.A Purpose – Aa SOP shu mate chhe?

Aa SOP follow kari ne koi pan new website page, service page, product page, collection page ke blog mate right keywords find kari shakay chhe.

Keyword research no main goal fakt high search volume vala keywords find karvano nathi. Main goal chhe:

  • Customer je search kare chhe e keywords find karva.
  • Business sathe relevant keywords select karva.
  • Search intent samajhvo.
  • Competitor na keyword gaps identify karva.
  • Ek keyword group ne correct page sathe map karvo.
  • Duplicate pages ane keyword cannibalization avoid karvi.

Team standard: Keyword research mate Semrush primary tool chhe. Existing website hoy to GSC data supporting evidence tarike use karo.

2.6.B Before Starting – Page requirement clear karo

  • Semrush open karta pehla aa details ready rakho:
  • Website domain.
  • Target country (example: United States).
  • Target location, if local SEO.
  • Page type: Product / Collection / Service / Blog / Location.
  • Page no main business purpose.
  • 3–4 validated SEO competitors.
  • Competitors find karva mate Coach 02 → 2.1 Competitor Pool Analysis follow karo.
  • Example:
  • Requirement Example
  • Website client-a-store.com
  • Niche Diamond Blades
  • Market United States
  • Target page Diamond Cup Wheel
  • Page type Product / Collection
  • Main goal Product sales

2.6.C Step 1 – Start with Semrush Keyword Gap

Tool path: SEO → Competitive Analysis → Keyword Gap

Keyword Gap thi competitors kaya keywords par rank kare chhe, pan aapni website kaya opportunities miss kare chhe e find kari shakay chhe.

  • Procedure
  • Semrush account open karo.
  • SEO → Competitive Analysis → Keyword Gap par jao.
  • First field ma aapni website enter karo (You).
  • Bija fields ma maximum four validated competitors add karo.
  • Badha domains no scope same rakho.
  • Organic keywords select karo.
  • Target country select karo.
  • Device select karo (Desktop / Mobile).
  • Available hoy to reporting date check karo.
  • You field correct chhe e verify kari Compare click karo.

Important: Organic SEO research mate Organic keywords use karo. Paid keywords ane PLA alag advertising research mate j use karo.

  • Understand Keyword Gap categories
  • Category Meaning Action

  • Weak Aapni position badha competitors karta weak chhe Existing page improve karo
  • Untapped Aapne rank nathi karta, pan at least one competitor kare chhe Relevant keywords shortlist karo
  • Strong Aapni position badha competitors karta better chhe Existing page protect karo
  • Unique Fakt aapni website rank kare chhe Existing strength protect karo
  • All Combined keyword list Overall research mate use karo

Remember: Aa labels selected competitors ane selected database ni comparison par based chhe. Aakha Google index nu representation nathi.

  • Process Missing and Untapped keywords
  • Missing tab open karo.
  • Keyword list review karo.
  • Untapped tab open karo.
  • Product/service sathe relevant keywords shortlist karo.
  • Competitor brand names ane irrelevant services remove karo.
  • Target country ane search intent check karo.
  • Shortlisted keywords next step mate save karo.
  • Example training phrase: diamond blade for porcelain

Aa phrase relevant hoy to j shortlist karo. Aanu presence example ma verified ranking, volume ke gap claim nathi.

  • Process Weak keywords
  • Weak tab open karo.
  • Aapni positions 11–20 vala keywords thi initial review sharu kari shako.
  • Keyword ni ranking position par hover/click kari exact ranking URL check karo.
  • Existing page open karo.
  • Competitor pages sathe intent, content, products ane internal links compare karo.
  • Decide karo: Improve existing page ke New page?

Strong ane Unique keywords pan separately review karo, jethi already successful pages accidentally weaken na thay.

2.6.D Step 2 – Shortlist keywords and check business relevance

  • Keyword Gap mathi malela badha keywords use karvana nathi.
  • Dar keyword mate aa questions pucho:
  • Shu keyword aapna actual product/service sathe related chhe?
  • Shu target country na customers aa search kari shake?
  • Shu search intent aapna planned page sathe match thay chhe?
  • Shu keyword commercial/business value dharave chhe?
  • Shu competitor no page aa keyword mate relevant chhe?
  • Search intent:
  • Intent User ni need Page type
  • Informational Information joiye Blog / Guide
  • Commercial Compare karvu chhe Category / Comparison
  • Transactional Buy / Order karvu chhe Product / Service
  • Navigational Specific brand/page joiye Brand page

Volume high hoy pan business relevance na hoy to keyword reject karo.

2.6.E Step 3 – Expand keywords with Keyword Magic Tool

  • Tool path: SEO → Keyword Research → Keyword Magic Tool
  • Have Keyword Gap mathi malela relevant keywords ne vadhu expand karo.
  • Procedure
  • Keyword Magic Tool open karo.
  • Main seed keyword enter karo.
  • Target country database select karo.
  • Search click karo.
  • Broad Match, Phrase Match, Exact Match ane Related filters review karo.
  • Keyword variations collect karo.
  • Question keywords separately identify karo.
  • Volume, KD %, Intent ane available CPC data review karo.
  • Irrelevant keywords remove karo.
  • Relevant keywords export/save karo.
  • What to check
  • Metric Shu check karvu
  • Volume Monthly search demand
  • KD % Organic ranking difficulty estimate
  • Intent User ni search need
  • CPC Paid advertising competition/value indicator, organic difficulty nathi
  • Keyword variations Same topic na related searches
  • Questions FAQ ane informational content ideas

KD low hoy etle ranking guaranteed nathi. Business relevance ane SERP hamesha check karva.

2.6.F Step 4 – Use Keyword Overview to validate important keywords

  • Tool path: SEO → Keyword Research → Keyword Overview
  • Keyword Magic Tool mathi select karela important keywords ne individually validate karo.
  • Procedure
  • Keyword Overview open karo.
  • One primary candidate keyword enter karo.
  • Target country database select karo.
  • Search click karo.
  • Volume ane KD % check karo.
  • Search intent check karo.
  • Trend ane available SERP information review karo.
  • SERP ma kaya type na pages rank kare chhe e check karo.
  • Relevant keyword variations ane related questions note karo.
  • Same process top keyword candidates mate repeat karo.
  • SERP validation:
  • Top results Product pages hoy to Product page plan karo.
  • Top results Category pages hoy to Category page plan karo.
  • Top results Blogs/guides hoy to Informational content plan karo.
  • SERP intent match na thay to keyword reject karo athva page strategy reconsider karo.

Tool metrics estimate chhe. Final decision actual search results ane business requirements par lo.

2.6.G Step 5 – Build keyword groups with Keyword Strategy Builder

  • Tool path: SEO → Keyword Strategy Builder
  • Aa step ma selected keywords ne structured content plan ma convert karvana chhe.
  • Procedure
  • Keyword Strategy Builder open karo.
  • Main seed keyword athva selected keyword list add karo.
  • Target country/project settings verify karo.
  • Keyword groups ane topic clusters review karo.
  • Similar meaning ane same search intent vala keywords ek group ma rakho.
  • Main topic ne Pillar keyword tarike identify karo.
  • Supporting keywords ne Cluster keywords tarike group karo.
  • Questions ne FAQ/subtopic ideas tarike identify karo.
  • Different intent vala keywords ne separate groups ma rakho.
  • Final keyword groups save/export karo.
  • Pillar and Cluster example
  • Role Example
  • Pillar topic Diamond Blades
  • Cluster 1 Diamond Cup Wheels
  • Cluster 2 Bridge Saw Blades
  • Cluster 3 Concrete Cutting Blades
  • Cluster 4 Porcelain Cutting Blades

Aa example content structure samjavva mate chhe. Actual page groups Keyword Strategy Builder na data ane SERP intent pramane final karva.

2.6.H Step 6 – Map keywords to the correct page

Have research complete chhe. Have decide karo ke kaya keyword mate new page banavvo ane kaya mate existing page update karvo.

  • Page mapping rules
  • One page = One primary keyword.
  • Same search intent vala 3–5 related secondary keywords same page par target kari shako.
  • Different intent vala keywords ne forcefully ek page par combine na karo.
  • Same keyword mate unnecessary duplicate pages create na karo.
  • Existing relevant page hoy to pehla ene improve karvano option check karo.
  • Keyword action decisions
  • Situation Action
  • Relevant keyword, no suitable page New page needed
  • Relevant keyword, existing page ranks weakly Improve existing page
  • Same intent and duplicate page Merge / consolidate
  • Irrelevant product or service Not relevant
  • Insufficient evidence Needs review
  • Master Keyword Map
  • Client ni existing Google Sheet → Keyword Map tab update karo.
  • Required details:
  • Keyword
  • Gap type
  • Country / Date / Device
  • Intent
  • Volume
  • KD %
  • Our position / URL
  • Competitor position / URL
  • Proposed URL
  • Action
  • Priority
  • Status

New page publish karta pehla existing Keyword Map ma keyword search karo. Same intent mate biji page already hoy to duplicate page na banavo.

2.6.I Step 7 – Finalize keyword selection

  • Final keyword select karta pehla aa five factors check karo:
  • Business relevance: Keyword actual product/service sathe match thay chhe?
  • Search intent: User ni need ane page type match thay chhe?
  • Search demand: Search volume ane keyword variations useful chhe?
  • Competition: KD ane actual SERP competition manageable chhe?
  • Page opportunity: New page create karvo ke existing page improve karvo?

Low-volume keyword pan valuable hoy shake chhe, especially B2B ane niche industries ma. Fakt volume na karane relevant keyword reject na karo.

2.6.J Free research sources – Short fallback

Semrush available na hoy athva additional ideas joiye tyare:

  • Tool Use
  • Google Autocomplete Real search phrase ideas
  • People Also Ask Questions for FAQ and headings
  • AnswerThePublic Question-based keyword ideas

Existing website mate GSC → Performance → Search results → Queries open kari existing search opportunities check karo.

Aa sources supporting research mate chhe. Main keyword selection process Semrush-first j rahe.

2.6.L Final Quality Checklist

  • Complete keyword research tyare j mark karo jyare badha applicable checks complete hoy.
  • Research setup
  • Page purpose ane target audience clear chhe.
  • Target country ane database correct chhe.
  • You domain correct chhe.
  • Competitors validated chhe.
  • Organic keywords selected chhe.
  • Keyword research
  • Keyword Gap ma Missing, Untapped ane Weak opportunities check kari.
  • Relevant competitor keywords shortlist karya.
  • Keyword Magic Tool ma keyword variations research kari.
  • Volume, KD % ane Intent review karya.
  • Keyword Overview thi important candidates validate karya.
  • Actual SERP ane ranking page types check karya.
  • Keyword Strategy Builder ma pillar/cluster groups banavya.
  • Page mapping
  • Every keyword business-relevant chhe.
  • Search intent ane planned page type match thay chhe.
  • Existing ranking URLs check karya.
  • Keyword cannibalization check kari.
  • One primary keyword per page final karyo.
  • Secondary keywords same-intent group ma add karya.
  • Master Keyword Map update kari.
  • New / Improve / Merge / Not relevant action assign karyu.
  • Final handover
  • Final keyword list save/export kari.
  • Country, device ane reporting date record kari.
  • Proposed URL ane priority record karya.
  • Research evidence ane source data save karya.

Final output: Approved primary keyword + 3–5 relevant secondary keywords + search intent + proposed URL + keyword mapping entry + recommended action.
