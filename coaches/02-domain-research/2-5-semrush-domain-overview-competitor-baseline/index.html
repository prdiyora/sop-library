🌐 2.7 — Semrush Domain Overview - Competitor Baseline

Dabbo 02 · Domain Research & Selection · ✅ Done

📋 Sheet: Aa stop nu data Semrush Research sheet na "Domain Overview" tab ma bharo. (Template ni copy banavvi hoy to link par click karo — "Make a copy" button aavse.)

2.5.A Aa stop su chhe

Semrush ma client ke competitor nu domain nakho etle e no full health card male - authority, traffic estimate, keywords, backlinks, ane Semrush Rank. Aa j baseline numbers chhe, je pachhi progress compare karva mate vaprashe. Real run: Client A (diamond blades, US), 19 Nov 2026 - numbers doc ma jeva teva j rakhela chhe.

2.5.B Semrush Domain Overview (step-by-step)

Goal: competitors ke keywords select karta PEHLA domain baseline establish karvi.

Step 1: Analysis taiyar karo

Project brief sathe confirm karo: website, target country, device ane reporting month. Darek competitor mate same settings vapro.

Working example, real run 19 Nov 2026: client-a-store.com, Root Domain, United States database, desktop, report date Nov 18 2026. Results: Authority Score 8 (Low authority), Organic Traffic 205 (-29%), Organic Keywords 725 (+5.2%), Paid Traffic 0, Paid Keywords 0, Backlinks 6.5K, Referring Domains 1.7K. AI Visibility: 14 Mentions ane 9 Cited Pages. Google SERP positions distribution: Organic 94.3%, AI Overviews 5%, other features 0.7%.

Step 2: Saacho report kholo

Jupiter → Semrush → SEO → Competitive Analysis → Domain Overview kholo. Domain nakho (unrelated page path vagar). Root Domain select karo; Subdomain, Subfolder ke Exact URL fakt tyare j jyare e narrow scope intended hoy.

Target database select karo ane Search/Analyze click karo. Landing page Worldwide default batave ke bija koi nu database yaad rakhe — darek vaar check karo.

Step 3: Headline metrics note karo

Pehla note karo: report date, database, device ane scope. Pachhi: Authority Score, estimated Organic Traffic, Organic Keywords, Paid Traffic, Paid Keywords, Backlinks ane Referring Domains (dekhay to).

AI Visibility, Mentions ane Cited Pages dekhay to ALAG columns ma rakho. Alag metrics ne add na karo. Blank widget = unavailable data, zero NATHI.

Step 4: Trends ane intent vacho

Consistent periods ma organic traffic ane keyword trends juo. Sudden changes note karo ane cause assign karta pehla report notes check karo.

Country distribution, branded/non-branded traffic ane keyword intent juo. Motu global total e proof nathi ke site client na target country sudhi pohche chhe. Koi widgets narrow scope select karva pan root-domain level j rahe — widget note vacho.

Step 5: Detailed reports kholo

Top Organic Keywords ane Main Organic Competitors ma View details thi jao. Relevant keywords ane competitor domains validation mate save karo.

Page-level research mate Top Pages/Organic Rankings ane link research mate Backlinks kholo. Pehla 5 preview rows thi akho content plan nakki NA karo.

Step 6: Example par kaam karo

Client A mate check karo ke dekhata competitors ane keywords stone tools, diamond blades, polishing pads ke actual product range vishe chhe ke nahi. Same-naam vala unrelated stone businesses reject karo.

Tool competitor suggest kare to "Candidate" tarike note karo — enu website, products ane target market check sudhi approve NAHI. High Authority Score etle j koi competitor approved nathi.

Step 7: Baseline save karo

Tracker columns: Research date | Domain | Scope | Database | Device | Report month | Authority Score | Organic traffic estimate | Organic keywords | Referring domains | Trend | Relevant competitor candidates | Next action.

Plan allow kare to report export karo. Project na dated research folder ma save karo. Unavailable fields "Not available" marked rakho.

Step 8: Final quality check

Authority Score = Semrush metric, Google score NATHI. Koi pan score ke traffic estimate rankings ni guarantee nathi.

Final quality gate (tick karo)

  • Saachu domain, scope, country, device ane month.
  • Estimates ne estimates tarike label karya — GA4 users ke GSC clicks nahi.
  • Preview rows select karta pehla full ma kholyu.
  • Competitors product ane market relevance mate validated.
  • Output: ek baseline record + researched competitor shortlist.

2.5.C Semrush Rank (step-by-step)

Goal: ek country database ni andar domain-level organic visibility compare karvi.

Step 1: Score vaparta pehla samjo

Semrush Rank domains ne estimated organic search traffic pramane order kare chhe (Semrush ni regional database ma). Nanno rank number = vadhu organic visibility.

Aa keyword ni Google position NATHI, Authority Score nathi, quality grade nathi, Alexa rank nathi. Agreed keyword set ane specific target location mate Position Tracking vapro.

Step 2: Semrush Rank kholo

SEO → Extras → Semrush Rank kholo. Interface ma je regional database ane reporting month/date dekhay e select karo.

Client A ane ena competitors mate agreed target market consistently vapro. Domains compare karta pehla actual displayed country ane month note karo.

Step 3: Rank table review karo

Capture karo: Rank, Domain, SE Keywords, SE Traffic ane Costs, plus Paid Keywords/Paid Traffic (dekhay to). Shortened column labels mate tooltips hover karo.

SE Keywords = database na Google top 100 ma observed organic keywords. SE Traffic = estimated monthly organic visits. Costs = estimated paid-search equivalent, actual spend ke revenue NATHI.

Step 4: Relevant domains shodho

Available search/filter controls ke current table thi target shodho. Na male to "Not found in this database/report" lakho — rank zero assign NA karo.

Useful comparison mate target + validated competitors same country/month mathi collect karo. Motu general marketplace context aapi shake pan automatically direct business competitor nathi.

Step 5: Winners & Losers juo

Winners & Losers kholo (available hoy to). Previous month sathe organic/paid keywords ane traffic na changes juo. Gains ane declines sort karo.

Deltas sathe current values pan juo; nana sites mota percentage changes batave. Gain = research lead, proof nathi ke koi specific SEO tactic e e karyu.

Step 6: Detailed domain report kholo

Domain click karo — Domain Overview khulse. Relevance, country distribution, non-branded keywords ane top pages validate karo.

Real run 19 Nov 2026 (US database, Nov 18 2026): Semrush Rank table ma 41,385,763 ranked domains chhe, top ma youtube.com, facebook.com, wikipedia.org ane reddit.com. Same day na US Compare Domains run ma: detroitdiamondtools.com 1.3M, taitsales.com 1.4M ane client-a-store.com 2.8M. Nanno number = vadhu estimated organic visibility, etle banne validated competitors hal Client A thi aagal chhe aa database ma.

Step 7: Reproducible comparison save karo

Available hoy to CSV/Excel export karo. Tracker: Research date | Country database | Report month | Domain | Semrush Rank | SE keywords | SE traffic estimate | Estimated Costs | Monthly change | Relevance note | Next investigation.

Original export ane settings rakho. Future periods same database ane method sathe compare karo — regional ranks mix na karo.

Step 8: Final quality check

Semrush estimates eni keyword coverage par depend kare chhe. Low-traffic ke local site paase real useful customers hoi shake, aa report ma data ocho hoy to pan.

Final quality gate (tick karo)

  • Lower-is-better interpretation saachi rite vaprayu.
  • Rank ne keyword positions ane Authority Score thi alag rakhyo.
  • Darek domain mate same database/month.
  • Missing domain number invent karya vagar record thayu.
  • Output: domain visibility benchmark + relevant trend leads.

2.5.D Expected Output

Output: ek baseline record (tracker row) per domain - client + top competitors. Aa numbers pachhi Position Tracking ane reporting ma compare thashe.
