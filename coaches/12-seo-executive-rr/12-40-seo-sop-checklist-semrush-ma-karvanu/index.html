🎓 12.40 — SEO SOP Checklist (SEMrush ma karvanu)

Dabbo 12 · SEO Executive RR · ✅ Done

12.40.A 1. Backlink Audit

  • SEMrush > Backlink Audit tool kholo
  • Domain nakho, run karo
  • Toxic backlinks find karo (Toxic Score high hoy tevા)
  • Toxic links ni list export karo (.txt file)

12.40.B 2. Toxic Links Disavow karo

  • Export karel .txt file ne Google Search Console na Disavow tool ma upload karo
  • Link: https://search.google.com/search-console/disavow-links
  • Correct property (domain) select karvanu bhulso nahi

12.40.C 3. Backlink Gap

  • SEMrush > Backlink Gap tool kholo
  • Apna domain + 2-3 competitors nakho
  • Jya competitors na backlinks che pan apna nathi — evi opportunities note karo
  • New backlink building mate list banavo

12.40.D 4. Rich Results Check (Schema Test)

  • Page URL check karva mate:
  • Link: https://search.google.com/test/rich-results
  • Schema markup errors/warnings joyo, fix karo

12.40.E 5. Site Performance

  • SEMrush > Site Audit ma jaine Performance/Core Web Vitals joyo
  • Slow pages, image size, loading issues note karo

12.40.F 6. Site Audit

  • SEMrush > Site Audit run karo (weekly/monthly)
  • Errors, Warnings, Notices check karo
  • Priority: Errors > Warnings > Notices

12.40.G 7. Position Tracking

  • SEMrush > Position Tracking ma keywords add karo
  • Ranking daily/weekly track karo
  • Rank drop thay to reason check karo (competitor, algo update, technical issue)

12.40.H 8. Link Building

  • SEMrush > Link Building tool ma prospects joyo
  • Outreach list banavo
  • Follow-up track karo

12.40.I 9. On-Page SEO Check

  • SEMrush > On Page SEO Checker
  • Suggestions joyo (title, meta, content, internal links)
  • Priority pages par pehla apply karo

Quick Order (Monthly Routine):

Site Audit → Backlink Audit → Disavow (jo jaruri hoy) → Backlink Gap → Link Building → Position Tracking → On-Page SEO → Rich Results Check
