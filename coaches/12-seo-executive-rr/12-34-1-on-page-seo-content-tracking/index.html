🎓 12.34 — 1. On-Page SEO & Content Tracking

Dabbo 12 · SEO Executive RR · ✅ Done

12.34.A Q: On-Page SEO ટ્રેકિંગ માટે કઈ શીટ અને શું વર્કફ્લો વાપરો છો?

Answer: "Google Sheets/Excel ma On-Page SEO Tracker maintain karu chu — jethi darek page nu status track thay, duplicate titles avoid thay, ane future updates easy bane."

  • Sheet na Main Columns:
  • URL | Page Type | Target Keyword | Secondary Keywords | Search Intent |---|---|---|
  • Image Alt | Internal Links (In/Out) | Word Count
  • GSC Clicks/Impressions | Current Rank | Core Web Vitals Status | Last Updated | Status | Priority
  • Quick Technical Limits:
  • SEO Title: 50–60 characters (approx. 580px)
  • Meta Description: 150–160 characters (approx. 960px)
  • H1 Tag: Single H1 per page, aligned with primary search intent
  • Update Cycle Strategy:
  • New Page: Publish karta pela entire baseline validation
  • Blog / Informational: Publish pela + 3–6 month ma refresh audit
  • E-commerce / Product Page: Jyare details, specs, or price change thay
  • Core / Money Pages: Quarterly structured performance review
  • Standard On-Page Workflow:
  • Keyword Research & Mapping → Intent Analysis → Title/Meta Optimization → Clean URL Formatting → Single H1 Implementation → Image Alt Optimization → Schema Markup → Internal Link Distribution → QA Audit → Publish → GSC Indexing Request → Rank & Performance Tracking

12.34.B Q: Meta Keywords add karo cho?

Answer: "Na, bilkul nahi. Google ranking mate Meta Keywords use nathi karto (officially deprecated since 2009). Primary + secondary keywords ane semantic entities (NLP entities) par focus karu."
