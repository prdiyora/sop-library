⚙️ 7.6 — GTM event list

Dabbo 07 · Setup & Tracking · ✅ Done

7.6.A Step by step (GTM)

  1. GTM container ma GA4 Configuration tag (Measurement ID) - All Pages.
  2. Niche ni list pramane GA4 Event tag + trigger banavo.
  3. GTM Preview mode ma test; GA4 DebugView ma event dekhay chhe?
  4. Publish. Version name ma date lakho.
  5. GA4 Admin → Events ma jo key event mark karvo hoy to "Mark as key event".

7.6.B Ecommerce site (GA4 recommended event names)

Event nameKyare fire thay
view_item_listCategory / collection page par products list dekhay
select_itemUser list mathi product par click kare
view_itemProduct page khule
add_to_cartAdd to cart click
begin_checkoutCheckout sharu
purchaseOrder success (value + currency + transaction_id)

7.6.D Etsy-style / outbound-sale site

click_buy_etsy (custom)"Buy on Etsy" button click (item + page parameters)

7.6.E Badhi sites

  • scroll depth 25/50/75/90 (06 GA4 Scroll Depth Check), file_download, newsletter_signup (sign_up), video_play.
  • Internal traffic filter ON, cross-domain jo checkout alag domain par hoy.

7.6.F Check

  • Event names lowercase + underscore, ek j spelling dar site par.
  • Dar event par page_location auto aave; item/button name parameter lakho.
  • Key events 3-5 j (badhu nahi).
