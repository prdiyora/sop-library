7.7.B SEMrush Position Tracking - Setup

Step-by-step SOP for keyword ranking monitoring and weekly reporting

1. Purpose and weekly schedule

Use Position Tracking to monitor Client A’s keyword rankings and compare visibility with competitors.

Complete the reporting task every Monday at 7:00 AM.

Save the complete keyword ranking data in the master SEO tracking spreadsheet. Keep each week’s snapshot so rankings can be compared over time.

WhenTask
Initial setupCreate the Position Tracking project for Client A and configure target market/keywords.
Every Monday, 7:00 AMOpen Overview → Rankings Overview and export/capture all keyword metrics.
Weekly reviewIdentify improved, declined, unchanged and newly appearing keywords.

2. Open Position Tracking

Log in to SEMrush.

Open the /position-tracking/ section (Position Tracking).

Enter the Client A domain and click “Set up tracking”.

3. If the website-monitoring limit appears

Message: “You’ve reached your limit of websites to monitor.”

Open the Projects area in SEMrush.

Review the project list and identify a project that is genuinely obsolete and occupying the shared account limit.

Do not automatically delete the first project. Verify its name, domain, owner and whether another team member still needs it.

Only after confirming it is unused and deletion is approved, open its three-dot menu and choose Delete.

In the “Delete project?” popup, read the prompt and enter the exact confirmation code shown by SEMrush into the confirmation field.

Confirm deletion only after verifying the selected project is safe to remove.

Return to Position Tracking and retry setup. If no project can safely be deleted, ask the account owner/admin to free capacity.

4. Create the Client A project

Go to Home → SEO → Position Tracking.

Click “Create project”.

In Website, enter the Client A domain. In Name, enter the project name.

Click Create and complete any additional setup fields requested by SEMrush, including target location, search engine, language, device and tracking keywords.

FieldValue
Websitehttps://client-a-store.com/
Nameclient-a-store

Use the approved target country and keyword list for Client A. The sample “India (Google) • English” is only an example; select the actual target market for the project.

Wait approximately 5–10 minutes for the project to become available. Actual processing time may vary.

5. Confirm the project is ready

Open the project and confirm the domain, target location, search engine, language and last updated time.

Check the number of tracked keywords and competitor configuration.
