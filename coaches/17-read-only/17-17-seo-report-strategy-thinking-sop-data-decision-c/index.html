📈 17.17 — SEO Report — Strategy & Thinking SOP (Data → Decision → Content → Deploy)

Dabbo 17 · Read Only (Reference) · ✅ Done

Aa stop shu chhe: Client A no report banavati vakhte me je mind ane strategy vapri, e akhi aa stop ma lakhi chhe. Kayo data joyo, emathi shu samjayu, ane pachhi rewrite, nava blog, nava collection ke fix nu suggestion kem aapyu, e badhu ahi chhe.

Aa stop vanchi ne tame koi pan client (Shopify, WordPress, lead-gen, blog) no report same logic thi banavi shako. Technical setup (Composio, JS extractor code, env vars) mate juo: 17.15 SEO Live Report SOP. Aa stop thinking + content + deploy mate chhe.

17.17.A Akho process 1 page ma

  1. Client ne samjo → shu vechay chhe, paisa kya thi aave chhe, brand naam shu chhe
  2. Data lo (3 period) → GSC pages + queries (7 / 28 / 90 days, comparison sathe), GA4 Organic
  3. Data ne 6 sawal pucho → (17.17.C) — darek sawal ek report section banave chhe
  4. Pages pasand karo → Rewrite (3), New blog (5–8), New collection (3–5), Fix (8–10)
  5. Site live vancho → top 10 pages: title, meta, H1, alt, schema, content
  6. Content lakho → darek suggestion = "Data reason + Shu badalvu + Exact navu text"
  7. Report banavo → sections ane design (17.17.F)
  8. QA → Deploy → GitHub → Vercel → client ne link (17.17.H)

Ek line ma strategy: Google already je page ne batave chhe (impressions) pan click nathi madta (low CTR / position 8–20), e pages ne pehla sudharo. Google je queries mate tamari site batave chhe pan matching page nathi, e mate navu page banavo.

Aa line tame yaad rakhsho to badha decisions emathi j nikle chhe.

Kem 3 period?

  • 7 divas: aa week shu thayu. Navi queries jaldi dekhay chhe.
  • 28 divas: main report period. Ek mahina ni stable picture aape chhe.
  • 90 divas: trend saacho chhe ke nahi e khabar pade (Client A: 904 → 2,420 clicks). Nava blog ke collection na ideas 90 divas na data parthi j aapva, karan ke tyare j data puratu hoy chhe.

17.17.C Data ne 6 sawal (aa j "mind" chhe)

Data aavya pachhi seedha report na banavo. Pehla aa 6 sawal pucho. Darek sawal no jawab report no ek section bane chhe.

Sawal 1: "Overall site upar jay chhe ke niche?"

  • Clicks, impressions, CTR ane position na totals current vs previous sarkhavo.
  • Client A 28d: Clicks 743 → 843 (upar), Impr 68.5K → 65K (thoda niche), CTR 1.1% → 1.3% (upar).
  • Matlab: impressions thodi ghati pan clicks vadhya. Etle je traffic aave chhe e vadhu relevant chhe. Aa positive story chhe.
  • Rule: Clicks upar ane impr niche hoy to CTR sudharyo chhe. Clicks niche ane impr upar hoy to position ke snippet ni problem chhe.

Sawal 2: "Kayu content kaam kare chhe?" (Blog vs other pages)

  • URL ma /blogs/ hoy e blog. Baki badhu collection, product, home.
  • Client A: top impressions vala pages ma ghana blogs chhe (cutting-metal-with-a-skil-saw 5,711 impr, choose-the-right-blade 3,990). Matlab: blogs traffic laave chhe, pan revenue collections/products thi aave chhe. Etle blog → collection internal link sauthi mahatva nu kaam chhe.

Sawal 4: "Loko shu search kare chhe?" (Keywords)

  • Branded (Client A, Client A stone products): aa loko tamne already jane chhe. Aa SEO nu kaam nathi, brand nu chhe. Alag tab ma rakho.
  • Non-branded (akemi, porcelain sink, tenax proseal): aa SEO nu saachu result chhe. Main tab.
  • Dhyan: "akemi" ke "tenax" product brand chhe, store brand nathi. Etle e non-branded gane.

Sawal 5: "SEO thi business ne shu malyu?" (GA4)

  • Organic sessions, users, engagement, orders, revenue.
  • Client A: 821 organic sessions pan revenue $0, key events 0. Sales nathi thata evu nathi, tracking j nathi.
  • Rule: Revenue 0 hoy to pehla tracking check karo. Report ma "tracking not set up" lakho ane Fixes ma High priority aapo. Khota orders kyarey na mukvana.

Sawal 6: "Shu karvu?" (Action, 17.17.D)

Upar na 5 sawal mathi je pages ane queries nikle, emathi Rewrite / New content / Fix nakki karo.

17.17.D Decision tree: Rewrite, New Page, ke Fix?

Query/page joyu
│
├─ Page chhe + impressions vadhu + CTR < 1% + position 4–20
│     └─► FULL PAGE REWRITE (title, meta, H1, body, FAQ — badhu navu)
│
├─ Page chhe + impressions vadhya pan position ghati
│     └─► SEO-FOCUSED REWRITE (Google navi queries test kare chhe → e queries page ma umero)
│
├─ Page chhe + topic ni queries position 30+ par
│     └─► SEO-FOCUSED REWRITE + collection ↔ blog internal links (topic "own" nathi thatu)
│
├─ Query ma impressions chhe pan MATCHING page j nathi
│     ├─ Informational query (how, why, what, can, best, vs, guide)  ─► NEW BLOG POST
│     └─ Commercial/product query (buy, sinks, blades, sealer, brand + product) ─► NEW COLLECTION
│
├─ Ek j intent ni 3+ queries, ane collection eni sathe match nathi kartu
│     └─► NEW COLLECTION (athva hal ni collection ne split karo)
│
└─ Page technical rite kharab (alt nathi, 2 H1, meta lambi, schema nathi, tracking nathi)
      └─► FIX (priority: High / Medium / Low)

Priority kevi rite nakki karvi

Priority score ≈ Impressions × (position 4–20 hoy to vadhu) × Business value (product/collection > blog)

  • Pehla e pages lo je already page 1 ni najik chhe ane paisa vala chhe (collections/products).
  • Position 50+ vala pages par pehla kaam na karo. Ema vadhu mehnat lage ane result late aave.

17.17.E Client A report ma darek suggestion kem aapyu (worked examples)

E1. Rewrite #1: /collections/porcelain-sinks → FULL PAGE REWRITE

Me shu joyu (data):

  • 28d: 3,471 impressions, fakt 17 clicks → CTR 0.5%, position 9.1
  • Top queries: "porcelain sink" 902 impr (pos 9.4), "porcelain kitchen sink" 313 impr (pos 9.8)
  • Live audit: meta description ma fakt "bathroom sinks" lakhyu chhe

Thinking:

  1. Impressions ghani chhe, etle Google page ne relevant mane chhe.
  2. CTR 0.5% chhe, etle loko snippet joi ne click nathi karta.
  3. Kem? Searcher "kitchen" sink shodhe chhe pan snippet ma "bathroom" lakhyu chhe. Intent mismatch.
  4. Position 10 chhe, etle page 1 nu chhellu sthan. Thodu content sudhre to top 5 ma aavi shake.
  5. Aa collection page chhe, etle direct paisa vala page chhe. Sauthi upar priority.

E2. Rewrite #2: /blogs/news/kitchen-sink-cabinet-combo-buying-guide → SEO-FOCUSED REWRITE

Data: impressions 365 → 1,203 (3 gana), pan position 4.4 → 10.2 (niche gayu). Navi queries: "kitchen cabinets for sink" (pos 37.2), "kitchen sink with cabinet" (13.5), "kitchen sink and cabinet combo" (10.1). Aa queries pehla na period ma nahotī.

Thinking:

  • Impressions vadhya ane position ghati, etle Google aa page ne ghani navi queries mate test kare chhe. Average position niche aave chhe karan ke nava, door na keywords umerata jay chhe.
  • Page aakhu kharab nathi, etle full rewrite nathi karvo. Fakt e navi queries ne page ma jagya aapvi chhe.

Shu badlvu (fakt aatlu):

  • Title ane meta ma exact phrase "kitchen sink and cabinet combo".
  • Intro na pehla 100 words ma "kitchen sink with cabinet".
  • Nava H2, darek ek navi query mathi: "Kitchen cabinets for sink: base sizes", "Cheap combo: what to check", "Ready-made vs custom".
  • Size table, FAQ, ane collection par link.

Rule: Navi query = navo H2 section. Google ne je query mate tame dekhao chho, e query no jawab page ma spasht hovo joie.

E3. Rewrite #3: Core drill bits (blog + collection) → SEO REWRITE + linking

Data: blog ma 1,684 impr pan fakt 6 clicks, pos 9.6. Collection pos 22.7. "what is a core drill bit" pos 49.3, "core drill bit" pos 36.3. Collection ma 2 H1.

Thinking: topic site par chhe pan Google ene topic no "owner" nathi manto. Blog ane collection ek bija ne support nathi karta, ane collection ma 2 H1 thi signal mix thay chhe.

Shu karyu:

  • Blog ma pehlo H2 "What is a core drill bit?" ane 40–50 words ni definition (featured snippet mate).
  • Collection ma ek j H1, 150 words nu intro, ane blog par link.
  • Blog thi collection par link, anchor "shop diamond core drill bits". Aam blog ane collection ek cluster bane chhe.

17.17.F Report ma shu batavvu, shu nahi (client psychology)

  1. Upar positive: clicks, CTR, gainers. Client pehla progress jove.
  2. Negative honest pan solution sathe: "Revenue 0" lakho, pan sathe "Fix: tracking setup" pan lakho.
  3. Darek number sathe period (Oct 6–Nov 2 vs Sep 8–Oct 5).
  4. Darek suggestion = Why + What + Exact text. Fakt "meta sudharo" na lakho, navo meta lakhi ne aapo.
  5. Branded alag tab ma. Client ne SEO ni saachi growth dekhay.
  6. Google search link (Search ↗) aapo jethi client jate position check kari shake.
  7. Report sections no order: Overview → Blog → Other pages → What changed → Keywords → GA4 → Rewrites → Ideas → Fixes.

17.17.H Report website ne Vercel par deploy karvi

Option 1: Snapshot report (HTML, aaj na data thi, sauthi saral)

  1. Report ni file index.html tarike save karo (ek j file, CSS ane JS andar).
  2. Navu folder banavo: client-seo-report-nov-2026/ → emaa index.html muko.
  3. <head> ma <meta name="robots" content="noindex, nofollow"> umero.
  4. GitHub: github.com → New repository → naam aapo → Private → Create → "uploading an existing file" → index.html drag kari ne muko → Commit.
  5. Vercel: vercel.com → Continue with GitHub → Add New → Project → repo pasand karo → Import.
  6. Framework Preset: Other. Build command khali rakho. Output directory pan khali.
  7. Deploy → 30 second ma your-dashboard.vercel.app link malse.
  8. Navo mahino: index.html badli ne GitHub par upload karo. Vercel jate redeploy karshe.

Option 2: Live report (Next.js + Composio + ChatGPT, data jate update)

  1. Project ZIP extract karo (app/, lib/, package.json, .env.example, README.md).
  2. GitHub par navo private repo banavo ane badhi files upload karo (ZIP nahi, node_modules nahi).
  3. Vercel → Import repo → Framework Next.js (auto detect).
  4. Environment Variables (Settings → Environment Variables):
NameValue
COMPOSIO_API_KEYComposio dashboard → API key
COMPOSIO_GSC_ACCOUNT_IDClient access vala GSC connection ni ID
COMPOSIO_GA4_ACCOUNT_IDClient access vala GA4 connection ni ID
GSC_PROPERTYhttps://client.com/ ke sc-domain:client.com

  2. Navo client = navo Vercel project. Same GitHub repo import karo ane fakt env vars badlo.

Pehla check karo: Composio ma je Google account connected chhe ema client ni GSC/GA4 property dekhay chhe ke nahi (LIST_SITES / LIST_ACCOUNT_SUMMARIES). Client A ma aa j bhool hati: connected account ma Client A j na hatu.

Security

  • Repo private rakho.
  • Vercel link jene male e joi shake. noindex thi Google ma nahi aave.
  • API keys kyarey code ma na lakho, fakt Vercel env vars ma.

17.17.I Darek navo report: 20-step checklist

Data

  1. Client profile bharyu (domain, GSC property, GA4 ID, brand terms, platform)
  2. Saachu Google account (property dekhay chhe)
  3. GSC pages + queries: 7 / 28 / 90 divas, comparison sathe
  4. GA4 Organic landing pages (sessions, users, orders, revenue)
  5. Duplicate (#anchor) URLs dedupe karya

Analysis

  1. Totals: upar ke niche? (Sawal 1)
  2. Blog vs other pages (Sawal 2)
  3. What changed: 6 signals (Sawal 3)
  4. Branded / non-branded split (Sawal 4)
  5. GA4 business result, revenue 0 hoy to tracking check (Sawal 5)

Decisions

  1. 3 rewrite pages (decision tree mujab, paisa vala page pehla)
  2. 5–8 blog ideas (90d data, question + pos ≤10 + page nathi)
  3. 3–5 collection ideas (ek intent ni 3+ queries)
  4. Top 10 pages live audit
  5. Fixes table (High / Medium / Low)

Content & build

  1. Darek suggestion = Why (numbers) + Shu badalvu + Exact text
  2. Report sections sacha order ma, period labels sathe
  3. QA: random 3–4 numbers GSC/GA4 sathe match, demo data nathi, mobile ma barabar

Deploy

  1. GitHub private repo → Vercel deploy → noindex
  2. Client ne link + 3 line summary (shu vadhyu, aa mahine shu karishu, shu fix karvu)

17.17.J Senior SEO ni jem vicharo (yaad rakhva jevu)

  • Impressions = Google no vishvas. Clicks = user no vishvas. Impressions chhe pan clicks nathi, etle snippet ke intent ni problem chhe.
  • Navi query = Google no hint. Google kahe chhe "aa topic mate tamne test karu chhu". Page ma eno jawab aapo.
  • Position 8–20 = sauthi saro ROI. Ochhi mehnat ma vadhu result male.
  • Blog traffic laave, collection paisa laave. Banne ne link thi jodo.
  • Pehla sudharo, pachhi navu banavo. Hal ni page ne rewrite karvu e navi page karta jaldi result aape.
  • Revenue 0 = pehla tracking check karo, SEO ne dosh na aapo.
  • Darek suggestion data thi. Data na hoy to suggestion na aapo, athva "hypothesis" lakho.
  • Measure karo: rewrite pachhi 2–4 week ma same page na CTR, position ane clicks sarkhavo, ane aavta report ma "Rewrite impact" section umero.
