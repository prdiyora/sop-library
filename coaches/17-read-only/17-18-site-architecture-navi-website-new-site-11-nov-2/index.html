🏗️ 17.18 — Read Only (Reference) — NAVI Website (New Site) — 11 Nov 2026

Dabbo 17 · Read Only (Reference) · ✅ Done

Aa blueprint koi pan website mate chhe — ecommerce, lead gen, blog ke service site. 1 website hoy ke 100, basic structure same rehse.

Sources: Google Search Central, Search Engine Land site architecture guide (2025–26), HubSpot silo guide.

Updated: 11 Nov 2026

Ek line ma samjo:

Homepage → Category/Hub pages → Sub-pages ane Blogs

  • Darek important page homepage thi 3 clicks ni andar hovu joie.

  • Money pages (je page thi sale ke lead male) 1–2 clicks ma hova joie.

  • Website no structure simple hoy, jethi Google ane visitor banne ne pages shodhva easy pade.

17.18.A 1. Architecture model pasand karo (99% sites mate same)

Website na pages kevi rite gothavva, tene architecture kahe chhe.

ModelShu chheKyare vaparvu
Hierarchical (tree)Homepage → Category → Sub-pages99% sites mate. Service, ecommerce, blog ane lead gen. Aa default model chhe.
Hub-and-spoke (topic cluster)Ek main pillar page hoy. Tena related blogs pillar page sathe link thay.Blog ane information section mate. Aa hierarchical structure ni andar j hoy.
DatabaseTemplate + data thi ghana pages bane. Amazon jevi site.Moti ecommerce site ke programmatic SEO mate. (03 → 11 Programmatic SEO)
Matrix / SequentialEk page sudhi ghana rasta hoy ke pages step-by-step chale.SEO mate avoid karo. Crawler confuse thai shake.

Default rule: Motabhag ni sites mate Hierarchical model lo. Blog mate eni andar Hub-and-spoke vapro.

17.18.B 2. Universal Page Map (koi pan niche)

Badhi websites mate basic structure same chhe. Fakat niche pramane page na names badlashe.

1. Homepage: Brand, main categories ane USP (tamari khas vaat) batavo. Money pages ni direct links aapo.

2. Hub / Category pages (3–7): Main topics na pages banao. Ecommerce ma collection pages, service site ma Services ane blog ma topic pillars. Main/head keywords ahi target karo.

3. Sub-pages: Product, alag service ke city pages banao. Long-tail keywords ane buyer intent ahi target karo.

4. Blog clusters: Darek hub niche 5–20 related blogs rakho. Badha blogs main hub sathe internal links thi joday. Pillar ↔ Cluster banne taraf linking rakho.

5. Must-have pages: About, Contact, Privacy, Terms ane ecommerce mate Shipping/Refund pages rakho. Aa trust ane E-E-A-T mate jaruri chhe. (05 → 05 Must-Have Pages)

17.18.C 3. Niche pramane page map (3 ready templates)

A. Ecommerce

Structure:

Homepage → Category (Collections) → Sub-category → Product

  • Product ne sachi category ni andar rakho.

  • Darek category mate related guide blogs banao.

  • Blogs mathi related product pages par internal links aapo.

  • Blog workflow: 03 → 07 Ecommerce Blog Workflow

  • Filters/variants na URLs mate main page taraf canonical set karo, jyare pages duplicate ke khub similar hoy. (09 → 03)

B. Lead gen / Service business

Structure:

Homepage → Services Hub → Individual Service Pages

  • Pela main Services hub banao.

  • Pachhi darek service mate alag page banao.

  • Buyer-intent keywords target karo, jem ke "cost", "quote", "near me".

  • Darek city ke service area mate page tyare j banao, jyare tya kharekhar service aapo.

  • Fakat ranking mate ek jeva city pages na banao. Aava pages ne doorway pages kahe chhe.

  • Trust mate case studies, reviews ane before/after proof pages banao.

Detail: 03 → 10 Lead Gen SEO

C. Blog / Content site

Structure:

Homepage → Topic Pillars (3–7) → Cluster Posts

Darek pillar mate:

  • 1 moto pillar post (2000+ words).

  • 10–30 related cluster posts.

  • Cluster posts mathi pillar par links aapo.

Aa rite ek main topic ni badhi information ek jagya sathe joday.

17.18.D 4. URL & Slug rules

1. Parent-child URL rakho

Examples:

  • /services/seo-audit

  • /category/product

Aa rite URL joi ne pan samjay ke page kai category ni andar chhe.

2. Slug short ane keyword-based rakho

  • Slug ma primary keyword vapro.

  • URL short rakho.

  • Words vachche hyphen (-) vapro.

Reference: 05 → 08 Slug = Keyword

3. Ek keyword-intent = ek URL

Ek j search intent mate 2 alag pages na banao.

Aavu karvathi keyword cannibalization (potana pages vachche competition) avoid thay.

4. Breadcrumbs rakho

Badha deep pages par breadcrumbs batavo.

Example: Home → Services → SEO Audit

Sathe BreadcrumbList schema pan add karo.

17.18.E 5. Internal linking map (asli ranking fuel)

Internal links etle potani website na ek page thi bija page par aapeli link.

1. Darek page par 3–5 contextual internal links rakho.

Links content sathe related hovi joie. (05 → 03)

2. Cluster → Pillar link aapo.

Blog post mathi main pillar page par link aapo. Aa pillar ni authority majbut karvama madad kare chhe.

3. Pillar → Money page link aapo.

Pillar mathi related product ke service page par link aapo. Aa link equity (link ni SEO value) money pages sudhi pahochadvama madad kare chhe.

4. Silo rule follow karo.

  • Ek topic na related pages vachche vadhu links rakho.

  • Bija topic par link jarur hoy tyare j aapo.

  • Aa rite topic ni authority clear rahe.

5. Orphan page na hovu joie.

Orphan page etle evo page jena par website na bija koi page mathi internal link nathi.

0 internal links vala pages avoid karo. (05 → 06 No Orphan Pages)

6. Navu page publish karo tyare link aapo.

Homepage ke top hub mathi nava page sudhi link pahochti hovi joie.

Google links follow kari ne nava pages shodhe chhe. Etle page crawl thavama madad male.

17.18.F 6. Depth & Crawl rules

3-click rule:

Homepage thi koi pan important page sudhi maximum 3 clicks ma pahochi shakay evo structure rakho.

  • Money pages: 1–2 clicks ma.

  • Bija important pages: maximum 3 clicks ma.

  • 4+ clicks deep pages avoid karo.

Deep pages sudhi crawler ne pahochvu mushkel thai shake. Aava pages ochha important lage ane crawl budget pan vadhu vapray shake.

Google mate aa fixed ranking rule nathi, pan website structure simple rakhva mate useful guideline chhe.

Moti site mate pan same rule:

Website par 1000+ pages hoy, to pan money pages ne homepage ke main categories ni najik rakho.

17.18.G 7. Technical foundation (publish pehla)

Website live karta pehla aa setup ready rakho.

SchemaSitewide Organization + WebSite schema. Page pramane Product, Service ke Article schema add karo. (08 → 04)

GSC + ClarityDay 1 thi setup karo. (07 Setup folder)

Mobile-firstWebsite mobile par sari rite chale ane content barabar dekhay.
Core Web VitalsSpeed ane user experience na Core Web Vitals pass karvano target rakho. (05 → 04)

17.18.H 8. Build order (navi site, week-by-week)

Navi website aa order ma banao.

WeekKaam
Week 1Domain setup (02 → 06). Keyword research + Master Keyword Map (02 → 07). Competitor pool (02 → 02). Website no page map paper ke sheet ma finalize karo.
Week 2Design setup (14 folder). Homepage + 3–7 hub pages + must-have pages live karo. GSC, GA4, Clarity setup karo. Sitemap submit karo.
Week 3–4Money pages (products/services) banao. Pela 5–10 cluster blogs publish karo. Internal linking karo. Fakat key pages mate indexing request moklo.
Month 2–3Vadhu cluster blogs banao. Off-page SEO start karo (06 folder). Pelo monthly report banao (11 folder).

Common mistakes — aa bhool na karo:

  • Homepage par badha pages ni links ek sathe dump na karo.

  • Category vagar badha products sidha homepage sathe na jodo.

  • Ek j keyword-intent mate 2 pages na banao.

  • Important pages ne 4+ clicks deep na rakho.

  • Navi site par Day 1 thi 100 thin pages (ochhi useful information vala pages) na banao. Aavu scaled content abuse ni risk ubhi kari shake chhe. Google spam policy dhyan ma rakho.

17.18.I 9. Checklist — NAVI site architecture finalize karta pehla

☐ Page map paper ke sheet ma ready chhe: Homepage → Hubs → Sub-pages → Clusters.

☐ Darek page nu primary keyword Master Keyword Map ma chhe. 1 intent = 1 URL.

☐ 3-click rule check karelo chhe. Money pages 1–2 clicks ma chhe.

☐ URLs parent-child format ma chhe ane slug ma keyword chhe.

☐ Internal linking plan ready chhe: Cluster post → Pillar ane Pillar → Money page.

☐ XML Sitemap ready chhe.

☐ Robots.txt, schema ane tracking ready chhe.

☐ Breadcrumbs on chhe.

☐ Koi orphan page nathi.
