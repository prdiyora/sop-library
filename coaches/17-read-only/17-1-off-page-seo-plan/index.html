📖 17.1 — Off-Page SEO Plan (Monthly)

Dabbo 03 · Strategy · ✅ Done

Source: SEO Playbook (Guide 2). Main rule: darek mahine badhu nahi — best opportunities pehla pick karo.

17.1.A Off-page nu goal

Mahina na priority pages ne authority ane brand support apvi. Backlink quantity goal NAHI — quality + relevance j count thay. Darek mahine badhu nahi — best opportunities pehla pick karo.

17.1.B Priority URLs kevi rite pick karva (GSC thi)

1. GSC thi shuru karo

GSC → Performance → Search results → Date: Last 3 months. QUERIES tab: kaya terms ne impressions/clicks/rank. PAGES tab: kaya URLs ne visibility.

GSC ma shu dekhaayShu karvu
Position 5–20 + good impressionsStriking distance → priority (jo intent + business value strong)
High impressions + low clicksTitle/meta, intent, SERP competition check (AI Overview chhe ke nahi pan juo)
Clicks aave pan Top 3 nahiContent + internal links + authority support
Impressions vadheDemand vadhe → right page rank thay chhe?
Same query par ghana URLsCannibalization → navo page banavta pehla review

Note: Position 5–20 ek filter chhe, rule nahi. Relevance, intent, business value, competition, quality pan juo.

2. Priority pages select karo

Site moti hoy to pan mahine thoda j pages par focus. Decide by: GSC impressions/clicks · ranking 5–20 · business value · seasonality · page ready chhe? · competition realistic.

Examples (site → focus): Nursery → Hydrangea collection + 2 products · Software → SEO/Web/Shopify service · Snacks → Healthy Snacks + Namkeen · Catering → Corporate + Wedding.

17.1.C Off-page execution rules

5. Off-page plan

Mahina na priorities + brand authority support. Backlink quantity goal NAHI.

  • Priority URL list pehla banavo.
  • Relevant, legit platforms; manipulation mate banela placements avoid karo.
  • Natural anchor mix: brand / URL / partial / topical; exact-match fakt jyare naturally fit thay.
  • Badha links homepage par nahi; deeper page tyare j jyare context support kare.
  • Same anchor repeat / mass low-quality nahi. Record: source, target, anchor, type, date, status.

17.1.D Month-end measure

7. Month-end measurement

  • Keyword position start vs end · priority-page clicks/impressions · CTR.
  • Organic traffic + leads · new referring domains · kaya blogs ne impressions · shu improve thayu + next action.
  • Same length period sathe compare karo (28 days vs previous 28 days); seasonal business mate YoY pan.

17.1.E Checklist

  • GSC 3 months (Queries + Pages) review karyu
  • Priority URLs + reason decide karela
  • Off-page URLs + anchor direction final karela
  • Record sheet updated: source, target, anchor, type, date, status
  • Baseline save karelu · month-end compare scheduled
