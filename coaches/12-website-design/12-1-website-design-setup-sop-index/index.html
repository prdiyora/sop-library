🖌️ 12.1 — Website Design Setup SOP - Index

Dabbo 12 · Website Design Setup · ✅ Done

Version 1.0 · 8 Nov 2026 · Aa folder koi pan website (navi ke juni) nu design header thi footer sudhi set karva mate chhe, ane website kyarey AI-made na lage e mate. Fresher pan follow kari shake; ke aa page koi pan AI ma paste kari ne design brief banavi shako.

Ek line ma rule: Design = brand ni potani vaat. Template/AI default (purple gradient, 3 same cards, emoji icons, stock smile) kyarey nahi. Real photo + real words + ek clear style.

12.1.A Order - kya thi sharu karvu

  1. 01 Design Philosophy - AI-na-lage rules, tells ni list (pehla vanchvu)
  2. 02 Fonts, Colors & Spacing - brand style fix karo (ek var, badhe same)
  3. 03 Header & Navigation - categories, sub-categories, mega menu, mobile menu
  4. 04 Homepage Section by Section - upar thi niche su aave, kya link jay
  5. 05 Footer - columns, legal, trust
  6. 06 Imagery, Icons & Copywriting - photos, icons, text human feel
  7. 07 Checklist & Reusable Template - fill-in tables (new site + existing site) + final QA

12.1.B Navi website vs juni website

CaseSu karvu
Navi website01 → 07 order ma. Pehla 07 ni template bharo (brand, palette, fonts, menu), pachhi design/build.
Juni websitePehla 07 ma 'Existing site audit' karo (AI tells + header/homepage gaps). Quick wins pehla: header, hero, fonts, colors. Pachhi baki. Ek sathe puro redesign nahi (SEO traffic jokham).

12.1.C Related SOPs (same SOP for Anyone folder)

  • 04 Design & Web Development → 01 UI-UX Human Feel, 02 Mobile Friendly, 03 Competitor Design Study, 04 New Features & Tools, 05 Theme, Motion & Consistency
  • 5.5 Must-Have Pages, 5.3 Internal Linking
  • 08 Technical SEO → Core Web Vitals / speed (design heavy na banavo)
Dhyan: Examples ma category/brand/colors sample chhe. Tamara business pramane badlo. Koi client name, income ke password aa docs ma nathi.
