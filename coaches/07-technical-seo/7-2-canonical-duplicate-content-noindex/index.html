🛠️ 7.2 — Canonical, Duplicate Content & Noindex

Dabbo 07 · Technical SEO · ✅ Done

💡 Navi site hoy to dhyan ma rakhjo: navi site na pages GSC ma turant dekhase nahi — index thava ma time lage. 1 mahina pachhi check karo, pehla ghabravu nahi.

Ek j content ghana URLs par khule (www/non-www, http/https, ?ref=, filters, variants) to Google ne pasand karvu pade ke kayu URL batavvu, ane links/signals vahenchai shake. Canonical tag Google ne kahe chhe: "aa content nu main URL aa chhe".

7.2.A Duplicate kya thi aave

  • http vs https, www vs non-www, trailing slash / vs no slash
  • Tracking parameters (?utm=, ?ref=), sort/filter parameters
  • Shopify: /collections/x/products/y ane /products/y - same product be URL
  • Print pages, tag pages, same description vala ghana product pages

7.2.B Fix kevi rite

  1. Self-canonical: dar indexable page par potana clean URL no canonical.
  2. Duplicate versions: main URL taraf canonical (ya 301 jo duplicate URL ni jarur j nathi).
  3. Site-wide 301: http → https ane www/non-www mathi ek j version.
  4. Noindex: je page users mate jaruri pan search mate nahi (thank-you, internal search, login) - meta robots noindex.
  5. Internal links: hamesha canonical URL ne j link karo - nahi to Google ne mixed signal male.

7.2.C Common mistakes (aa bhool na karo)

  • Noindex + robots.txt block sathe: robots block hoy to Google noindex tag vanchi j na shake
  • Canonical ek page par ane sitemap/internal links bija URL par - conflicting signals
  • Badha pages no canonical homepage par - pages index mathi nikli jay

Note: canonical ek hint chhe, order nahi (source: Google docs). Signals consistent hoy to j Google follow kare.

7.2.D Checklist

  • Ek j preferred domain version (https + www ya non-www), baki 301
  • Indexable pages par self-canonical
  • Sitemap
  • internal links + canonical - teno match
  • Noindex pages robots.txt ma blocked nathi
