🛠️ 7.4 — Crawl budget & JS

Dabbo 07 · Technical SEO · ✅ Done

7.4.A 1. Crawl budget kyare jovo

  • Site ma ghana hajar URLs (filters, tags, programmatic pages) hoy.
  • GSC → Settings → Crawl stats: requests, response codes, avg response time.
  • "Discovered
  • currently not indexed" ghana hoy.

7.4.B 2. Waste ghatadvo

  1. Parameter/filter URLs control (canonical, noindex, robots - 08/02, 08/03).
  2. Redirect chains ane 404 ghatadvo (08/03).
  3. Sitemap ma fakat indexable, 200-status, canonical URLs.
  4. Server speed (TTFB) saru - slow server = Google ochhu crawl kare.
  5. Strong internal links important pages ne (05/03).

7.4.C 3. Log files (advanced, optional)

  • Server log mathi Googlebot hits joi shakay: kaya URLs crawl thay, kaya nahi.
  • Tool: Screaming Frog Log File Analyser (ke hosting logs). Googlebot verify karo (fake bots hoy).
  • Important page Googlebot ne dekhatu nathi to internal link / sitemap sudharo.

7.4.D 4. JavaScript SEO

  1. Rule: important content + links normal HTML ma hova joiye (anchor tag with href).
  2. Test: GSC URL Inspection → View tested page → Screenshot/HTML. Content dekhay chhe?
  3. View-source vs rendered HTML compare. Content fakat JS thi aave to risk.
  4. Best: server-side rendering ya static HTML for money pages.
  5. Lazy-load images ma above-the-fold image lazy na karo.
  6. Click par j khulta tabs/accordion content ne Google read kare, pan fakat button click thi load thay (API call) to nahi.

7.4.E Checklist

  • Crawl stats joyu, 5xx nathi.
  • Important page rendered HTML ma content + links chhe.
  • Sitemap clean.
