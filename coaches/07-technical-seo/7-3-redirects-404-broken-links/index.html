🛠️ 7.3 — Redirects, 404 & Broken Links

Dabbo 07 · Technical SEO · ✅ Done

💡 Navi site hoy to dhyan ma rakhjo: navi site na pages GSC ma turant dekhase nahi — index thava ma time lage. 1 mahina pachhi check karo, pehla ghabravu nahi.

URL badlay, page delete thay, product band thay - dar vakhte saacho status code jaruri chhe. Galat handling = backlinks waste, users frustrated, crawl budget waste.

7.3.A Status codes simple bhasha ma

  • 301: kayam mate move thayu - page ni value nava URL ne pass thay. Slug change, domain change, pages merge mate.
  • 302: temporary move (sale page, A/B test). Lambo time 302 rakhvu nahi.
  • 404: page nathi. Normal chhe - badha 404 problem nathi.
  • 410: page kayam mate gayu - Google 404 jevu j treat kare (farak bahu nano).
  • Soft 404: page "nathi" kahe pan status 200 aape, ke badha deleted pages homepage par redirect - Google ene soft 404 gane.

7.3.B Kevi rite check karvu

  1. Semrush Site Audit crawl → 3xx report, 4xx filter.
  2. GSC → Pages → Not found (404) ane Soft 404 lists.
  3. Redirect chains: A → B → C hoy to A → C direct karo (max 1 hop).
  4. Redirect loop: A → B → A - page khule j nahi, tarat fix.

7.3.C Nirnay no niyam

  • 404 page par backlinks ke traffic hoy → nearest relevant page par 301
  • Koi value nathi ane replacement nathi → 404/410 rehva do
  • Internal broken link → link j update karo (redirect par aadhar na rakho)

7.3.D Checklist

  • Monthly crawl: 0 internal broken links
  • Koi redirect chain ke loop nathi
  • Backlink vala 404 pages ne 301 aapela
  • Search ane popular links sathe custom 404 page
