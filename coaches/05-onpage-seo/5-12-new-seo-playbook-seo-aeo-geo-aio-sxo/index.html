2. Old SEO vs New SEO (30 sec)

  • Old: Google ma rank thavu ej game — keyword + backlink.
  • New: Google
  • AI badhe retrieve + cite + trust thavu.
  • Ek line: pehla "rank" j goal hato; have "AI cite kare" e pan goal chhe.

3. Core idea (yaad rakho)

  • AEO = user na question no direct answer FIRST aapo (long intro nahi).
  • GEO = AI ne 4 vaat aapo — ENTITY (tame kon), ANSWER (question solve), ORIGINAL (navu useful info), TRUST (proof + reviews).
Analogy Google = busy teacher. "Answer aa file ma chhe" bolo — story nahi. GEO = smart waiter: tamari info clear hoy to j tamne confidently recommend kare.
Formulas AEO: ASK → ANSWER → FORMAT → PROVE → MEASURE GEO: ENTITY → ANSWER → ORIGINAL → TRUST → SOURCES → TEST

5.12.B PART B — KARVANU (blog/page par)

4. AEO — page checklist

Example: "Does piles medicine work immediately?" (health topic = YMYL, etle expert review jaruri)

  • H1 = question j.
  • Direct answer first (40–60 words).
  • Format intent pramane: para / list / table / steps.
  • H2 = follow-up questions (PAA): how long · what affects · how to support · when to see doctor.
  • FAQ = real questions (fake nahi).
  • Internal links → related page. (Article = island, link = bridge.)
  • Schema = page type pramane accurate Article/Product markup (fake nahi). [Note: Google e 7 May 2026 thi FAQ rich results band karya chhe — FAQ section user mate rakho, FAQ schema optional.]
  • Measure → GSC: impressions, clicks, CTR.
✕ Bad (answer chhupave)✓ Good (answer first)
"Piles is a common condition… various treatment options available…""No. Piles medicine immediately kaam nathi karti; kalak–days lage, type/severity par depend."

5. GEO — page + off-page checklist

  • Entity clear: brand, service, location; website + GBP + LinkedIn + directories = SAME info.
  • Original value: cost breakdown, data, case study (generic AI copy nahi).
  • Ecosystem: connected pages: service + location + cost + comparison + FAQ + reviews + About.
  • Off-page: relevant directories, reviews, mentions (consistent; quality > quantity).
  • Test: ChatGPT/Gemini/Perplexity ma query nakho: brand aavyu? cite thayu? → gap fix karo.

Platform (1 line) — [LIKELY / industry observation, official confirm nathi]: ChatGPT → entity + trusted sources · Gemini → entity + Google Business + local · Perplexity → original research + citations · Bing Copilot → Bing index + entity + local.

6. E-E-A-T (trust layer)

Experience · Expertise · Authoritativeness · Trustworthiness — AI/Google trust mange chhe. (Resume + reference check jevu: proof hoy to j trust.)

  • Author bio + credentials; YMYL (health/legal/finance) → expert review.
  • Credible sources cite karo; original data / real experience; honest claims + updated date.
  • Na karo: fake credentials, fake reviews, fake stats, unsupported claims.

7. LLMs.txt — [Sudharel] shu sachu chhe

  • Shu chhe: site root par Markdown file (example.com/llms.txt) je AI tools ne important pages ni list aape. llmstxt.org no proposal chhe, official web standard nathi.
  • Google Search (CONFIRMED): Google na 15 May 2026 na AI Search guide mujab llms.txt ni jarur nathi — Google Search, AI Overviews ke AI Mode eno use nathi kartu. Ranking ma help ke nuksan nathi.
  • Chrome Lighthouse: May 2026 thi Lighthouse llms.txt ne AI agents mate "emerging convention" tarike check kare chhe — etle te agents mate kaam nu hoi shake.
  • Biji AI platforms: ChatGPT/Perplexity eno use kare chhe evu officially confirm nathi. [SPECULATION]
  • Decision: Low priority. WordPress ma Yoast/RankMath thi free ma bane to banavo, pan client ne "AI citation mate jaruri" kahi ne vechho nahi. Pehla saru content, entity ane trust.

8. Mistakes + Template + Golden rule

Na karo: answer chhupavo, keyword stuffing, fake FAQ/reviews, wrong schema, generic AI copy, measure na karvu.

Template: Keyword · User question · Intent · Direct answer (40–60w) · 5 follow-ups · Format · Proof · 2–3 relevant internal links · Schema · CTA · AI test · Next action.

Golden rule User + AI banne ne clear, useful, trustworthy answer aapo. Flow: Structure → Retrieve → Cite → Trust → Convert.
