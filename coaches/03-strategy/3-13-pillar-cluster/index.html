🧭 3.13 — Pillar + cluster

Dabbo 03 · Strategy · ✅ Done

Ek line ma: Pillar pehla, sub-pages pachhi, darek sub-page pillar ne link kare, pillar badha sub-pages ne link kare.

3.13.A 1. Inventory banavo

  1. KSB list export karo: topic, pillar keyword, sub-page keywords, KD, volume.
  2. Live pages sathe match karo. Je page pehla thi chhe te dobaro nahi banavvu (1 keyword-intent = 1 URL, see 05 On-Page / 10 Keyword Mapping).
  3. Sheet banavo: Topic | Page type (Pillar/Sub) | URL slug | Primary keyword | Secondary keywords | KD | Volume | Status.

3.13.B 2. Pillar page pehla

  1. Top 5 ranking competitors kholo (USA ane UK banne market ni Google ma).
  2. Note karo: headings, topics covered, FAQ, entities (names/terms), depth (words), media, schema.
  3. Apdu page same coverage ane same depth rakhe, pan shabdo potana. Competitor nu text copy ke near-copy nahi (duplicate/plagiarism risk, brand ne nuksan).
  4. Pillar ma primary + secondary keywords naturally; title, H1, slug, first paragraph ma primary.
  5. EEAT: real author, real experience/photos, about + contact link, sources (see 05 On-Page / 01 EEAT).

3.13.C 3. Sub-pages pachhi

  1. Pillar live thay pachhi j sub-pages banavo, etle pillar nu link taiyar hoy.
  2. Darek sub-page ma: pillar ne 1 contextual link + 2-4 bija related sub-pages ne link (see 05 On-Page / 03 Internal Linking).
  3. Pillar page par sub-pages no clear list/section (card ke link list) mukho.

3.13.D 4. Quality gate

  • Pre-publish QA checklist pass (05 On-Page / 13).
  • Sitemap ma add, GSC ma URL Inspection → Request indexing (limited), 2-3 internal links.
  • Orphan page nathi (05 On-Page / 06).

3.13.E 5. Measure

  • Dar 2 hafta GSC ma pillar + cluster pages: impressions, clicks, position.
  • 4-6 week pachhi: je sub-page position 5-20 par chhe tene Content Improvement (03 Strategy / 02) mate lo.

3.13.F Common mistakes

  • Badha pages ek sathe thin content sathe. Quality pehla, speed pachhi.
  • Pillar ane sub-page same keyword par (cannibalization).
  • Sub-pages thi pillar ne link bhuli javu.
