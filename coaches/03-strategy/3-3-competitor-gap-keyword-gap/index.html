🧭 3.3 — Competitor Gap + Keyword Gap

Dabbo 03 · Strategy · ✅ Done

📋 Sheet: Aa stop nu data Competitor Gap + Keyword Gap sheet na "Gap Keywords" ane "Keyword Validation" tab ma bharo. (Template ni copy banavvi hoy to link par click karo — "Make a copy" button aavse.)

Competitors je keywords par rank kare chhe ane tame nahi - te list j tamari next 3-6 mahina ni content strategy chhe. Gap analysis = ready-made roadmap.

3.3.A Steps (pagla)

  1. Tool select karo: Semrush (Keyword Gap tool) (Content Gap), — Semrush j main tool + manual Google search.
  2. Tamaru domain vs 3-4 competitors enter karo.
  3. Filter: competitors top 20 ma, tame 50+ ke absent - te keywords export karo.
  4. Cluster karo: similar keywords ne group karo - ek group = ek page/blog (keyword cannibalization avoid karva).
  5. Priority set karo: Volume x (1/KD) x business relevance - je highest te pehla.

3.3.B Manual method (tool vagar)

  • Main keyword search karo, competitor na top pages open karo, temna H2/H3 topics note karo - tame cover karel nathi te gap chhe
  • Google "People Also Ask" ane "Related Searches" manually note karo (ke Semrush Questions / AlsoAsked jeva tools) - automated scraping nahi

3.3.C Output nu format

  • Sheet: Keyword | Volume | KD | Competitor ranking | Tamari status | Priority | Target page

3.3.D Checklist

  • Gap keyword sheet taiyar chhe (50+ keywords)
  • Clusters banavela (ek cluster = ek page)
  • Next content batch mate Top 10 priorities select karela chhe

3.3.E Semrush Keyword Overview (step-by-step)

Keyword ne content plan ma umerta PEHLA validate karvo — aa aa stop nu kaam.

Step 1: Ek keyword ready karo

Keyword Gap, Magic Tool ke client ni product list mathi ek candidate lo. Ek exact phrase thi chalu karo jethi enu intent dhyan thi check thai shake.

Working example, real run 19 Nov 2026: diamond blades, United States, desktop. Results: Volume 1.0K, KD 32% (Possible), Global Volume 6.4K (India 1.3K, US 1.0K, Philippines 480, Australia 390, UK 320, South Africa 320), Intent n/a, CPC $1.92, Competitive Density 1.00. Keyword Variations: 11.5K ideas, 125.1K total volume; top ones: raimondi diamond blade resin dressing stone (2.9K, KD 0%), diamond blade (1.9K, KD 9%), diamond saw blades (1.9K, KD 26%). Questions: 491 ideas, 4.7K total volume; top ones: how to dress a diamond blade (260), can a diamond blade cut metal (210), how to sharpen a diamond blade (210).

Step 2: Keyword Overview kholo

SEO → Keyword Research → Keyword Overview kholo. Phrase nakho, target country select karo, Search click karo.

Available hoy to aapnu domain nakhi personalized metrics lo. Domain box ane keyword box ma confuse na thav. Local location settings fakt tyare j, jyare local analysis karvu hoy.

Step 3: Keyword metrics note karo

Aa badhu capture karo: research date, database/location, device/date (dekhay to), Volume, Global Volume, KD %, Intent, Trend, CPC ane Competitive Density.

Domain-specific fields (PKD, Potential Traffic, Topical Authority) dekhay to ALAG rakho. KD = general competition; PKD = entered domain mate tailored. Data missing hoy to "Not available" lakho, zero NAHI.

Step 4: SERP ma intent confirm karo

SERP Analysis juo: update date, top relevant URLs ane SERP features. Pachhi nakki karo ke aa query mate su joie — collection, product page, guide, comparison ke local service page.

Example: buyer-focused blade query ne generic company About page sathe map na karo. Relevant competitors kholi ne samjo ke searcher su kaam puru karva maange chhe.

Step 5: Variations ane questions juo

Keyword Variations, Questions ane Keyword Strategy/cluster links kholo (je available hoy). Fakt e terms save karo je proposed page sathe fit thay.

Safe material use vishe question hoy to manufacturer ni verified guidance j jovi. Keyword suggestion mathi tool compatibility, blade size, RPM limits ke safety instructions IMAGINE NAHI.

Step 6: Validation pachhi bulk analysis

Shortlist (100 keywords sudhi) mate Bulk Analysis vapro. Run karta pehla count ane country check karo. Intent, Volume, KD, CPC ane bija selected columns juo.

Dhyan: bulk analysis ma local metrics ke historical snapshot single-keyword report jeva nathi milta. National ane city-level values ek j comparison ma MIX na karo.

Step 7: Decision ane evidence save karo

Tracker format: Keyword | Database/location | Research date | Intent | Volume | KD | PKD/domain (dekhay to) | Trend | SERP date/features | Top reference URLs | Target page | Keep/reject/review reason.

Jarur hoy to j selected terms ne properly named list ma save karo, ke CSV/XLSX export karo. Single-keyword report mate PDF save kari shako (plan permit kare to). Bija user ni shared list OVERWRITE NAHI.

Step 8: Final quality check

Volume estimates = guaranteed visitors nathi. Global Volume = client na target country ni demand nathi.

Final quality gate (tick karo)

  • Exact phrase ane country verify thay gayu.
  • Keyword intent ranking pages sathe check thay gayu.
  • KD, paid competition ane domain-specific PKD — tran alag samjaya.
  • Values ma collection date ane location chhe.
  • Output: validated keyword record, ek intended target page sathe.
⚠️ Sheet rule: Competitor Gap sheet na second tab ma SERP date, SERP features, Top reference URLs, Target page, ane Keep/Reject/Review reason — aa badha columns darek row ma align j raheva joiye. Column mismatch thay to e row sidhi Reject j ganay. "Target page" column khali = reject.
