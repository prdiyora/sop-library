🛒 9.3 — Filters, Variants & Duplicate Product URLs

Dabbo 09 · Ecommerce SEO · ✅ Done

Ecommerce sites par filters (color, size, price, sort) hajaro URLs banave chhe. Aa badha Google crawl/index kare to crawl budget waste thay ane index ma thin duplicate pages bharay (index bloat).

9.3.A Problem kevi rite olkhvo

  • GSC → Pages: indexed count products+collections thi ghanu vadhare
  • site:domain.com inurl:filter ke ?sort_by search
  • Screaming Frog ma parameter URLs ni count

9.3.B Decision (nirnay)

  1. Search demand vala filter ("black leather belt" - real volume) → alag optimized collection page banavo, filter URL nahi.
  2. Baki filters/sort → canonical main collection par, internal linking ma use na karo.
  3. Crawl waste motu hoy → robots.txt thi parameter patterns block (Shopify ma robots.txt.liquid). Pan dhyan: already indexed URLs pehla canonical/noindex thi nikalo, pachhi block.

9.3.C Shopify duplicate product URLs

  • /collections/x/products/y ane /products/y - Shopify canonical /products/y par set kare chhe
  • Pan theme collection page parthi /collections/.../products/... link kare to Google ne mixed signal - theme ma product links direct /products/ par karo
  • Variants (?variant=123) canonical main product par - alag page fakt jo variant nu potanu search demand hoy

9.3.D Checklist

  • Indexed filter/parameter URLs ni count track
  • High-demand filters mate dedicated collections
  • Theme product links /products/ format ma
