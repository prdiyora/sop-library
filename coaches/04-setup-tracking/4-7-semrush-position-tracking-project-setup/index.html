Step 2: Position Tracking kholo

  1. Semrush ma login karo.
  2. /position-tracking/ section (Position Tracking) kholo.
  3. Client A nu domain nakho ane "Set up tracking" click karo.

Step 3: "Website monitoring limit" error aave to

Message aave: "You've reached your limit of websites to monitor." Tyare aa karvu:

  1. Semrush ma Projects area kholo.
  2. Project list juo ane kayo project have kaam no nathi (obsolete) e shodho — e j shared account ni limit vapore chhe.
  3. Seedho pehlo project delete NA karo. Pehla check karo: naam, domain, owner, ane bija koi team member ne joie chhe ke nahi.
  4. Confirm thay ke e unused chhe ane delete karva approved chhe, to pachhi three-dot menu → Delete.
  5. "Delete project?" popup ma Semrush je exact confirmation code batave e type karo.
  6. Delete pehla ek vaar fari verify karo ke saacho project j select karyo chhe.
  7. Pachhi Position Tracking par pacho aavi ne setup retry karo. Koi pan project safely delete na thai shake to account owner/admin ne capacity free karva kaho.

Step 4: Client A project banao

  1. Home → SEO → Position Tracking ma jao.
  2. "Create project" click karo.
  3. Website ma Client A nu domain nakho. Name ma project naam nakho.
  4. Create click karo ane Semrush je fields maange e bharo: target location, search engine, language, device ane tracking keywords.
