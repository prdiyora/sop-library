10.9.B SEMrush Position Tracking - Weekly Review & Reporting

Step-by-step SOP for keyword ranking monitoring and weekly reporting

6. Open Overview → Rankings Overview

Open the “Overview” tab in the project.

Find the “Rankings Overview” section.

Review the complete tracked keyword list.

Capture every keyword and all available metric columns. Include Volume, Position, Potential Traffic, SF/SERP Features, Intent and any other useful columns shown.

Export the full table to CSV/XLSX if SEMrush provides an export option. If the table is paginated, include every page/row.

If export is unavailable, copy the complete table into the tracking spreadsheet. Do not save only the first visible rows.

8. Compare this week with last week

Keep each Monday’s export as a separate dated snapshot. Do not overwrite previous data.

Compare current Position with the previous Monday’s Position.

Mark Improved when the current position number is smaller; Declined when it is larger; Unchanged when it is the same.

Mark New when a keyword appears in this week’s data but was not in the previous snapshot.

If a previously tracked keyword disappears or has no position, verify the SEMrush report before marking it Lost / Not ranking.

Review major drops, new keywords and ranking URL changes. Record content, internal-link or technical follow-up actions where needed.

StatusHow to identify

9. Monday 7:00 AM checklist

Open SEMrush → Position Tracking.

Confirm the correct Skyline Stone project and target market.

Open Overview → Rankings Overview.

Export/capture all keyword rows, including all pages of the table.

Save Volume, Position, Potential Traffic, SF, Intent and other available columns.

Save a dated file, e.g. Skyline-Stone-Position-Tracking-YYYY-MM-DD.xlsx.

Add the snapshot to the master sheet without deleting previous weeks.

Compare rankings and mark improved, declined, unchanged and new keywords.

Write a short weekly summary of important ranking movements and actions.

10. Important notes

The learnosphere.in / India / 100 keywords screen is an example only. Use Skyline Stone’s domain and approved market settings.

Metrics and update frequency depend on SEMrush plan and project configuration. Record only fields actually available.

Confirm that the project data has updated before exporting. If it has not, record the displayed update time and check the account’s tracking schedule.

Do not delete a shared-account project without confirming that it is obsolete and obtaining approval. The confirmation code is a one-time UI confirmation and must not be stored in this SOP.

Keep historical weekly exports so ranking trends can be measured accurately.

How to use this example

Keyword: the exact tracked search query.

Intent: the search intent label shown by SEMrush (for example, I).

SF: the number of SERP features shown for the keyword.

KD %: Keyword Difficulty percentage.

Your Pot. Traffic / Your Pot. Growth: potential traffic and potential growth values shown by the report.

Pos. Nov 14 / Pos. Nov 19: ranking positions on the two comparison dates.

Diff: the change value displayed beside the related metric; preserve the report’s value/sign.

Visibility: the visibility percentage shown for the project.

Est. Traffic: estimated traffic attributed to the keyword/report row.

Vol. / CPC: search volume and cost-per-click values.

URL: the landing page currently ranking for that keyword.

Weekly instruction: Save all rows and all available columns from the Skyline Stone Rankings Overview every Monday. Keep the date-specific snapshots so position, visibility, traffic and keyword changes can be compared week to week.
