🏗️ 13.2 — Site Architecture — JUNI Website (Old / Existing Site) — 11 Nov 2026

Dabbo 13 · Site Architecture · ✅ Done

Aa SOP client ni chalu website ke apani juni website nu structure sudharva mate chhe.

Rule #1: Website par je saru chale chhe, tene bagadavu nahi. Pehla audit karo, pachi priority pramane problems fix karo. URL kharekhar jarur hoy to j badlo.

Updated: 11 Nov 2026

Ek line ma: Juni website nu structure sudharva mate:

Audit → Map → Blockers fix → Depth/Structure fix → Internal Linking → Results measure

Ranking bachavva mate: URL ochha badlo. URL badalvo pade to 301 redirect jarur lagavo.

13.2.A 1. Golden rules (juni site mate)

Rule 1: Ranking aapti URL jarur vagar badalvi nahi.

URL no slug saro na hoy, pan tena par traffic aavto hoy, to tene em j rakho. URL badalvo pade to juni URL thi navi URL par 301 redirect lagavo.

Rule 2: Ek vakhat ma ek j change batch karo.

Je changes karo, teni date Page Audit & Fix log ma lakho. Aathi khabar padse ke kaya change thi result aavyo.

Rule 3: Changes pachi 4–6 week result check karta raho.

Google ne pages farithi crawl karva ane changes samajva time lage chhe. Etle jaldi result joi ne changes undo na karo. (Google Starter Guide)

Rule 4: Changes karta pehla backup ane ranking snapshot lo.

Website no backup lo. Sathe current rankings, clicks ane impressions no record save karo.

Reference: 01 → 00 Onboarding, Phase 1 baseline

13.2.B 2. Step 1 — Full crawl & current map (day 1–2)

Juni website ma atyare su structure chhe, te pehla samjo.

1. Screaming Frog crawl karo (08 → 06). Badha URLs, titles, page depth, status codes ane canonicals export karo.

2. Depth report banao. Kaya pages sudhi pahochva 3 ke vadhare clicks lage chhe, teni list banao.

3. Orphan pages shodho. Je pages par website na bija koi page thi internal link nathi, tene orphan pages kahe chhe. GSC ane crawl data compare kari ne shodho.

4. GSC data export karo. Kaya pages par impressions ane clicks aave chhe, te juo. Aa pages ne khas dhyan thi handle karo, karan ke te already Google ma performance aape chhe.

5. Current website no tree diagram banao. Homepage thi kaya category, hub ane pages jodayela chhe, te paper ke Whimsical ma doro.

13.2.D 4. Restructure karvu hoy to (URL changes)

Website nu structure badalta URL pan badalvi pade, to aa steps follow karo.

1. 301 redirect lagavo. Juni URL thi navi URL par direct 301 redirect karo. Ek j hop hovo joie. Redirect chain na banavo.

2. Internal links update karo. Website na badha related links navi URL taraf badlo. Juni URL na redirect par bharoso na rakho.

3. Sitemap update karo. Navi URLs sitemap ma muko ane GSC ma sitemap fari submit karo.

4. GSC ma 2–4 week monitor karo. Clicks ane impressions check karo. Impressions ghate to turant karan shodho.

5. Moti restructure hoy to migration SOP follow karo. Jo ghani URLs ke website nu motu structure badlavanu hoy, to 08 → 07 Website Redesign & Migration follow karo.

13.2.E 5. Architecture fix patterns (je sauthi common chhe)

Pattern 1: Flat dump

Problem: Homepage par direct 50+ pages ni links chhe. Koi proper group ke structure nathi.

Fix: 3–7 hub pages banao. Related pages ne tena hub sathe jodo. Homepage par mukhya hub pages ni links rakho.

Pattern 2: Deep burial

Problem: Important money pages sudhi pahochva 4–6 clicks lage chhe.

Fix:

  • Homepage ke hub page thi direct link aapo.

  • Related products/posts widgets thi links aapo.

  • Khub important pages mate footer links pan aapi shako.

Pattern 3: Orphan blog posts

Problem: Blog posts publish thaya chhe, pan website na koi bija page thi tena par link nathi.

Fix: Hub/pillar pages banao. Tema related blogs ni links muko. Blog posts ni andar pan related pages na contextual links aapo.

Pattern 4: Cannibal clusters

Problem: Ek j keyword par 3 alag pages ranking mate compete kare chhe.

Fix:

  1. Master Keyword Map (02 → 07, section 8) sathe compare karo.

  2. Kaya page sauthi saro chhe, te nakki karo.

  3. Best page rakho.

  4. Bija pages ne jarur pramane merge karo ke 301 redirect karo.

Decision mate 10 → 03 na rules follow karo.

Pattern 5: Faceted nav bloat (ecommerce)

Problem: Product filters na alag-alag combinations thi hajaro URLs bani jay chhe.

Fix:

  • 09 → 03 pramane canonical/noindex rules set karo.

  • Sitemap ma fakta canonical URLs rakho.

13.2.F 6. 30/60/90 day plan (juni site)

Juni website nu structure ek j divas ma badlavanu nathi. Aa 90-day plan follow karo.

PeriodTarget
Day 1–30Full crawl karo, current map banao, blockers/404/duplicates fix karo, GSC baseline save karo ane quick-win titles improve karo (03 → 01)
Day 31–60Deep pages ne homepage/hub sathe link karo, hub pages banao, internal linking sudharo ane top 10 pages nu content refresh karo (03 → 02)
Day 61–90Topic clusters expand karo, off-page SEO karo (06), first full report banao (11) ane baseline sathe results compare karo

Common mistakes — aa bhool na karo:

  • Rankings no snapshot lidha vagar changes karva.

  • Badhi URLs ek sathe badalvi.

  • Redirect chains banavvi, jem ke A → B → C.

  • 301 redirect karya pachi pan internal links ma juni URLs rakhvi.

  • Fakta 2 week ma result judge kari ne changes undo kari deva.

  • URL changes pachi sitemap update karvanu bhuli javu.

13.2.G 7. Checklist — JUNI site architecture fix

☐ Full crawl export ane baseline snapshot lidhelo chhe.

☐ Koi noindex, robots ke canonical blocker baki nathi.

☐ 404 errors ane broken links 0 chhe, athva known issues mate proper redirect lagavelo chhe.

☐ Duplicate URL problems canonical ke 301 redirect thi solve thai gai chhe.

☐ Important money pages sudhi 2 clicks ni andar pahochi shakay chhe.

☐ Koi orphan page baki nathi.

☐ Darek badleli URL mate 301 redirect lagavelo chhe ane internal links update karya chhe.

☐ Sitemap GSC ma resubmit karyo chhe ane monitoring schedule set chhe.

☐ Darek change ni date log ma lakheli chhe.
