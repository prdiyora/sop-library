🛠️ 8.4 — Schema Markup (Structured Data)

Dabbo 08 · Technical SEO · ✅ Done

Schema = code (JSON-LD format) je Google ane AI systems ne page vishe clear facts aape: aa product chhe, price aatlo, brand aa, business kya chhe. Schema direct ranking boost nathi aapto (CONFIRMED), pan rich results (stars, price) ane machine understanding mate useful chhe.

8.4.A Website type pramane jaruri schema

  • Badhi sites: Organization (logo, socials, contact), WebSite, BreadcrumbList
  • Local business: LocalBusiness (NAP, hours, geo) - GBP sathe exact match
  • Ecommerce: Product
  • Offer (price, availability, currency), review/rating fakt jo real reviews page par visible hoy
  • Blog: Article/BlogPosting (author, datePublished, dateModified)

8.4.B Important 2026 update

Google e 7 May 2026 thi FAQ rich results Search ma batavvana band karya chhe (CONFIRMED - Google Search Central). FAQ section page par users ane AEO mate hju useful chhe, pan FAQ schema thi have rich result nahi male. Pehla HowTo (2023) ane bija ghana types pan retire thaya chhe - navo schema add karta pehla Google docs ma type supported chhe ke nahi check karo.

8.4.C Steps

  1. Page type pramane schema type select karo.
  2. Implement: WordPress ma RankMath/Yoast, Shopify ma theme ma default Product schema hoy - check karo, jarur hoy to app/JSON-LD.
  3. Validate: Rich Results Test (Google) + validator.schema.org.
  4. Monitor: GSC → Enhancements/Shopping reports ma errors.

8.4.D Common mistakes (aa bhool na karo)

  • Page par na dekhaye tevi info schema ma (fake rating) - manual action risk
  • Schema price ane page price alag
  • Duplicate schema - theme + plugin banne add kare

8.4.E Checklist

  • Organization
  • Breadcrumb site-wide
  • Product/Article/LocalBusiness page type pramane
  • Rich Results Test pass, GSC ma errors 0

8.4.F Added 8 Nov 2026 — FAQ schema final status

  • June 2026 ma Google e FAQ rich result report (GSC) ane Rich Results Test mathi FAQ support pan kadhya — documentation pan remove thayu. [CONFIRMED — Google Search Central]
  • Juno FAQ schema delete karvani jarur nathi — Google pramane unused structured data 'does not cause problems'. Pan navi pages ma FAQ schema banavva time na ghasvo; FAQ section users/AEO mate content tarike j rakho.
