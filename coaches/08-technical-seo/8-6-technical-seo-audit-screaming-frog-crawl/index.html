🛠️ 8.6 — Technical SEO Audit (Screaming Frog Crawl)

Dabbo 08 · Technical SEO · ✅ Done

6 Month Plan na Month 1 ma "full audit" lakhel chhe - aa doc te audit kevi rite karvo te batave. Audit = list of issues nahi, priority sathe action plan.

8.6.A Steps

  1. Crawl: Screaming Frog (free 500 URLs) ma domain nakho. Mode: Spider.
  2. Response codes: 3xx, 4xx, 5xx ni list (Technical point 03).
  3. Indexability: noindex, canonicalised, blocked pages - intentional chhe? (Technical point 01, 02).
  4. Page titles + meta: missing, duplicate, limit karta vadhare lamba.
  5. H1: missing, ek karta vadhare, duplicate.
  6. Images: alt text missing, size moto.
  7. Crawl depth: money pages 3 clicks thi vadhare deep na hova joiye.
  8. GSC data sathe match: Pages report, Core Web Vitals, manual actions, security issues.

8.6.B Priority kevi rite nakki karvi

  • Critical: site/money pages index nathi, noindex/robots bhool, site-wide redirect issue - tarat
  • High: money pages par duplicate/canonical issue, broken internal links, slow mobile
  • Medium: meta missing, alt text missing, redirect chains
  • Low: cosmetic (title thodu lambu)

Rule: "Ketla URLs affected" x "te pages ni business value" = priority. 500 blog tags par missing meta < 5 product pages noindex.

8.6.C Output

  • Sheet: Issue | Example URLs | Count | Impact | Effort | Priority | Owner | Status

8.6.D Checklist

  • Full crawl thai gayu + GSC data sathe cross-check karyu
  • Issues priority sathe listed
  • Critical issues 1 week ma fixed

8.6.E Added 16 Nov 2026 - Audit ma extra checks

Big/programmatic site hoy to crawl-budget ane log-file analysis pan add karo

Multi-country (USA + UK) hoy to hreflang tags pan check karo

Step 3: "Website monitoring limit" message aave to

Message: "You've reached your limit of websites to monitor." Tyare:

  1. Alag browser tab ma https://semrss.jupiterseotool.com/home kholo.
  2. Projects area shodho ane e project shodho je have jaruri nathi ane shared account ni project limit vapore chhe.
  3. Kai pan delete karta PEHLA verify karo: exact project naam/domain, obsolete chhe, unused chhe, ane bija koi team member ne nathi joitu. Active project ke bija nu jaruri kaam delete NA karo.
  4. Confirmed obsolete project mate three-dot menu → Delete.
  5. Confirmation code maange to on-screen process follow karo ane code FAKT Semrush interface ma j nakho. Code chat ma share na karo ke SOP ma store na karo.
  6. Semrush Site Audit par pacho aavi ne page refresh karo. Limit release thay gayu e confirm karo.

Safety rule: Project delete = destructive action. Project owner ke purpose clear na hoy to ATAKO ane approval lo. Fakt etla mate delete na karo ke e list ma pehlu dekhay chhe.

Step 8: Full Site Audit PDF export karo

  1. Audit report ma kona ma PDF/export option click karo.
  2. "Report template" popup ma "Site Audit: Full report" select karo.
  3. Report template load thava ~1 minute wait karo.
  4. "Export settings" unchanged rakho (aa workflow pramane).
  5. Export options ma "Download PDF" select karo. Email sharing ke online dashboard NATHI (alag thi request hoy to j).
  6. PDF client na designated folder ma save karo.
  7. Consistent filename vapro: Skyline-Stone-Site-Audit-YYYY-MM-DD.pdf.
  8. Downloaded PDF barabar khule ane full report hoy e confirm karo.

Step 9: PDF review karo ane fix list taiyar karo

  1. Akho PDF beginning thi end sudhi vacho. Fakt summary score thi review NA karo.
  2. Semrush je darek issue report kare e list karo: affected URL(s), issue description, severity/priority ane recommended action (dekhay to).
  3. Issues ne type pramane group karo jethi similar fixes ek sathe thai shake.
  4. Priority: pehla critical errors, pachhi high-priority warnings, pachhi lower-priority notices. Website badalta pehla actual impact confirm karo.
  5. Fix implement karta pehla check karo ke issue aa page/site mate valid chhe ke nahi. Koi audit recommendations site ni intended setup par lagu nathi padti.

Step 10: Fixes implement ane verify karo

  1. Approved fix tracker par kaam karo — highest-impact issues thi chalu karo.
  2. Edit karta pehla affected URL, page type ane issue details confirm karo.
  3. Yogya platform/CMS ke technical configuration ma change karo.
  4. Change pachhi affected URL recheck karo: page load thay chhe ane fix e bija page ke function todyu nathi e confirm karo.
  5. Verification pachhi j item "Fixed" mark karo. Fix na thai shake to reason note karo ane Open ke Not applicable rakho.
  6. Developer access, code changes, redirects, robots directives ke server configuration joie e issues responsible developer ne assign karo — unreviewed change na karo.
  7. Completed fixes ane unresolved items nu record rakho — aavta somvar na audit mate.

Step 11: Important operating notes

  • 1,000-page crawl limit = aa process nu requested setting. Semrush report kare ke site limit exceed kare chhe to limitation note karo ane appropriate crawl scope par agree karo — assume na karo ke darek URL audit thayu.
  • 139/500 pages valo example report Skyline Stone no expected result NATHI. Hamesha actual page count ane configured limit record karo.
  • Crawl duration vary thay. 2–5 minute setup wait, 15–20 minute initial crawl ane 10-minute progress checks — aa operational estimates chhe, guaranteed Semrush processing times nathi.
  • PDF report ane fix tracker same weekly folder ma sathe rakho jethi week-to-week progress compare thai shake.
  • Projects delete, production settings badalvi ke risky technical fixes — ownership, impact ane approval confirm karya vagar NAHI.
