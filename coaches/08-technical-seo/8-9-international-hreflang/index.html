🛠️ 8.9 — International & hreflang

Dabbo 08 · Technical SEO · ✅ Done

OptionExampleKyare

8.9.B 2. hreflang (jo be ke vadhu versions hoy)

  1. Darek version page par badha j versions ni hreflang tag (potani sahit - self reference).
  2. Codes: en-US, en-GB, x-default (fallback).
  3. Return links jaruri: US page UK ne point kare to UK page US ne point kare.
  4. Absolute URLs, canonical same page par self.
  5. Implement: HTML head, ke sitemap ma. Ek j method rakho.

8.9.C 3. Content localisation

  • UK spelling (colour, jewellery) vs US (color, jewelry), UK vs US keywords alag check karo (Semrush ma database US ane UK).
  • Currency, shipping time, returns, VAT/tax notes, size units.
  • Pure copy-paste duplicate nahi - thodu localise.

8.9.D 4. Measure

  • GSC → Performance → Country filter (United States / United Kingdom).
  • GA4 ma country wise sessions + key events.

8.9.E Mistakes

  • Automatic IP redirect (Googlebot ne block thai jay) - bhale suggestion banner aapo.
  • hreflang return link na hovi.
