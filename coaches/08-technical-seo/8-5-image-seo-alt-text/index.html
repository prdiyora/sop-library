🛠️ 8.5 — Image SEO & Alt Text

Dabbo 08 · Technical SEO · ✅ Done

Images speed na sauthi common karano ma ek ane Google Images traffic no source - banne. Ecommerce ma product images j sales kare chhe.

8.5.A Rules (niyamo)

  1. File name: upload pehla rename - IMG_4521.jpg nahi, eggless-chocolate-cake.webp.
  2. Alt text: image ma su chhe te 5-15 words ma describe karo. Keyword naturally aave to saru, stuffing nahi. Decorative images mate alt empty.
  3. Format: WebP (ya AVIF), compress karelu. Product image 100-200 KB target.
  4. Size: display size jetli j image - 4000px image 400px box ma nahi.
  5. Width/height attributes: layout shift (CLS) avoid karva.
  6. Lazy load: fold ni niche ni images lazy. Page ni main (LCP) image lazy nahi.

8.5.B Ecommerce extra (vadhu)

  • Har product ni unique real photos - manufacturer ni same images badha sellers pase hoy
  • Alag-alag angles + use-case photo + size reference
  • Variant images alag (color pramane)

8.5.C Kevi rite check karvu

  • Screaming Frog → Images → Missing alt text, over 100 KB
  • PageSpeed Insights → "Properly size images", "Serve images in next-gen formats"

8.5.D Checklist

  • Content images ma Missing alt text 0
  • Varnanatmak file names
  • WebP
  • compressed, LCP image lazy nathi
