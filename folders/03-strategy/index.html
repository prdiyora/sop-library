Quick Win - Top 4-10 Pages nu Title & Description

Je pages Google ma position 4-10 par chhe (first page, pan top 3 ma nathi)

  • tenu title ane meta description improve karo. Aa sauthi fast ROI valo SEO move chhe: content change karva jevu effort nahi, pan CTR ane ranking banne improve thay.

Steps

  1. Search Console kholo → Performance → Pages. Position 4-10 vala pages filter karo.
  2. Impressions vadhare, CTR ocho vala pages pehla select karo - title/description no j problem chhe.
  3. Title rewrite karo: primary keyword first, number/power word add karo (da. "2026", "Best", "Guide", "Free"), 50-60 characters.
  4. Description rewrite karo: benefit
  • CTA + keyword, 150-160 characters. Question format CTR vadharave (da. "Looking for X?").
  1. 2-4 week wait karo ane CTR/position compare karo.

Title formulas je work kare

  • [Number]
  • [Keyword] + [Benefit] → "7 Eggless Cake Designs je Surat ma Famous chhe"
  • [Keyword]
  • [Year] + [Brand] → "SEO SOP 2026 | RadhaVision"
  • How to + [Keyword] + [Result] → "How to Choose Domain Name je Rank kare"

Checklist

  • Top 4-10 position vala pages identify karya (GSC)
  • Title: keyword pehla, 50-60 chars, power word
  • Description: faydo + CTA, 150-160 chars
  • Changes na dates noted (before/after compare karva)

10-20 Pages nu Content Improvement

  • content j improve karvu padshe. Second page = Google page ne relevant mane chhe pan enough quality/depth nathi.

Steps (pagla)

  2. Top 3 competitor pages vanchho same keyword mate - temna ma su chhe je tamara ma nathi?

Competitor Gap + Keyword Gap

Competitors je keywords par rank kare chhe ane tame nahi - te list j tamari next 3-6 mahina ni content strategy chhe. Gap analysis = ready-made roadmap.

Steps (pagla)

  1. Tool select karo: Semrush (Keyword Gap tool), Ahrefs (Content Gap), ke free option - Ubersuggest + manual Google search.
  2. Tamaru domain vs 3-4 competitors enter karo.
  3. Filter: competitors top 20 ma, tame 50+ ke absent - te keywords export karo.
  4. Cluster karo: similar keywords ne group karo - ek group = ek page/blog (keyword cannibalization avoid karva).
  5. Priority set karo: Volume x (1/KD) x business relevance - je highest te pehla.

Manual method (tool vagar)

  • Main keyword search karo, competitor na top pages open karo, temna H2/H3 topics note karo - tame cover karel nathi te gap chhe
  • Google "People Also Ask" ane "Related Searches" manually note karo (ke Semrush Questions / AlsoAsked jeva tools) - automated scraping nahi

Output nu format

  • Sheet: Keyword | Volume | KD | Competitor ranking | Tamari status | Priority | Target page

Checklist

  • Gap keyword sheet taiyar chhe (50+ keywords)
  • Clusters banavela (ek cluster = ek page)
  • Next content batch mate Top 10 priorities select karela chhe

Step 1 — Project ni taiyari (10 min)

Keyword shodhta pehla aa vaat sheet ma lakhi do. Aa vagar keyword research disha vagar nu thay.

  1. Target country: Client kya vechhe chhe? (US / UK / India). Semrush ma database aaj country no select karvo — Global volume par decision na levo.
  2. Business goal: Sale joie chhe (product/category) ke traffic + trust (blog)?
  3. Site type: Shopify ecommerce / service / local / blog.
  4. Existing pages: Site par pehla thi kaya pages chhe — sitemap ke Shopify admin mathi list kaadho. (Step 5 ma cannibalization check mate joie.)
  5. [v1.1 navu] Seasonality: Google Trends ma seed keyword nu 5-year trend (target country) juo. Keyword seasonal hoy (Christmas gifts, back to school, Diwali) to page season thi 2-3 mahina pehla publish karo — Semrush nu volume 12 mahina nu average chhe, peak mahina ma demand ghanu vadhare hoi shake. [CONFIRMED — Semrush volume = monthly average]

Step 2 — Seed keyword research

[v1.1 navu] 2A. Existing site hoy to pehla GSC (free ane sauthi accurate)

  1. GSC → Performance → Search results → last 3 months → Queries tab.
  2. Filter: Position 8 thi 30 + impressions vadhare. Aa keywords par Google tamari site ne already relevant maane chhe — sauthi jaldi result aa j aape.
  3. Query par click → Pages tab: kayo page rank thay chhe te note karo (Step 5 ma Update decision mate).
  4. Aa list 'GSC Opportunities' tab ma muko. Semrush data sathe match karo — GSC real chhe, Semrush estimate.

2B. Keyword Overview (Semrush)

  1. Semrush → Keyword Overview → seed keyword nakho (example: meal planner template) → database = target country (example: US).
  2. Jovu: Volume (target country nu), KD%, Intent, CPC, SERP features (images, PAA, AI Overview, shopping).
  3. Niche 'Questions' list joi lo — aa FAQ / H2 ideas mate kaam aavse. Export kari lo.

2C. Keyword Magic Tool (Keyword ideas)

  1. 'Keyword ideas' → View all → Keyword Magic Tool khulse. Database = target country.
  2. Broad match tab rakho (sauthi vadhare ideas). Example result: 748 keywords, total volume 18,720, average KD 26%.
  3. Filters lagavo: Volume ≥ 50 (niche ma 20 pan chale), KD% ≤ tamari site ni capacity (navi/low authority site mate 0-30 thi sharu karo), Language = English.
  4. Left side na groups (example: printable, free, weekly, family, google sheets) joi lo — aa j pachhi cluster ideas bane chhe.
  5. Export → sheet ma 'Raw Keywords' tab ma paste karo.
Senior tip KD ni limit fix number nathi. Strong DA/backlinks vali site 40-50 KD par pan rank kari shake; navi site mate 0-25 thi start karvu safe chhe. Pehla tamari site kaya KD na keywords par already page 1 par chhe e GSC + Semrush Organic Research ma juo — e tamari 'safe KD range' chhe. [LIKELY — industry practice]
[v1.1 navu] Semrush na hoy to — free alternatives • Google Search Console: existing site mate sauthi saro source (real queries). • Google Keyword Planner: volume ranges (exact number ad spend vagar nathi male), country select thay. • Google autocomplete, People Also Ask, Related searches: long-tail ane question keywords. • Google Trends: seasonality ane rising topics. • KD nu manual check: top 10 ma kon chhe juo — moti brands/marketplaces j hoy to agharu; forums, nana blogs, juna pages hoy to chance chhe. Process same rahe — fakt data sources badlay.

Simple priority score (sheet ma column banavo):

Priority = Business Value (1-3) × Intent match (1-3) × Opportunity (1-3, volume vadhu + KD ochhu = 3)

Score 18-27 = pehla banavo, 8-17 = pachhi, 1-7 = skip. Aa formula andha thai ne na vaparvu — client e koi product push karvu hoy to te upar aave. [v1.1 navu] GSC ma position 8-30 vala keywords ne +1 Opportunity aapo — tya page already chhe.

Step 4 — Keyword Strategy Builder: Topic, Pillar, Cluster

  1. Semrush → Keyword Strategy Builder → seed keyword(s) nakho → country select → 2-3 min ma SERP analyze thase.
  2. All Pages / Topics tab: dar topic ma ek pillar page + ena cluster pages dekhase. Example: Topic: printable meal planner templates — Total volume 97,590, Avg KD 32.52%.
  3. Dar topic nu naam + volume + KD sheet ma 'Topic Map' tab ma save karo.
  4. Topic par click → pillar page keyword (example: meal planner template) par click → tena related keywords + KD + volume malse. Aa pillar page na secondary keywords chhe.
  5. 'Potential SERP competitors and content references' na 10 URLs copy karo — Step 6 ma vaparvana chhe.
  6. Puro topic (pillar + clusters + keywords) ek sathe sheet format ma export kari lo — data accurate rahe.

Pillar + cluster

Ek line ma: Pillar pehla, sub-pages pachhi, darek sub-page pillar ne link kare, pillar badha sub-pages ne link kare.

1. Inventory banavo

  1. KSB list export karo: topic, pillar keyword, sub-page keywords, KD, volume.
  2. Live pages sathe match karo. Je page pehla thi chhe te dobaro nahi banavvu (1 keyword-intent = 1 URL, see 05 On-Page / 10 Keyword Mapping).
  3. Sheet banavo: Topic | Page type (Pillar/Sub) | URL slug | Primary keyword | Secondary keywords | KD | Volume | Status.

2. Pillar page pehla

  1. Top 5 ranking competitors kholo (USA ane UK banne market ni Google ma).
  2. Note karo: headings, topics covered, FAQ, entities (names/terms), depth (words), media, schema.
  3. Apdu page same coverage ane same depth rakhe, pan shabdo potana. Competitor nu text copy ke near-copy nahi (duplicate/plagiarism risk, brand ne nuksan).
  4. Pillar ma primary + secondary keywords naturally; title, H1, slug, first paragraph ma primary.
  5. EEAT: real author, real experience/photos, about + contact link, sources (see 05 On-Page / 01 EEAT).

3. Sub-pages pachhi

  1. Pillar live thay pachhi j sub-pages banavo, etle pillar nu link taiyar hoy.
  2. Darek sub-page ma: pillar ne 1 contextual link + 2-4 bija related sub-pages ne link (see 05 On-Page / 03 Internal Linking).
  3. Pillar page par sub-pages no clear list/section (card ke link list) mukho.

4. Quality gate

  • Pre-publish QA checklist pass (05 On-Page / 13).
  • Sitemap ma add, GSC ma URL Inspection → Request indexing (limited), 2-3 internal links.
  • Orphan page nathi (05 On-Page / 06).

5. Measure

  • Dar 2 hafta GSC ma pillar + cluster pages: impressions, clicks, position.
  • 4-6 week pachhi: je sub-page position 5-20 par chhe tene Content Improvement (03 Strategy / 02) mate lo.

Common mistakes

  • Badha pages ek sathe thin content sathe. Quality pehla, speed pachhi.
  • Pillar ane sub-page same keyword par (cannibalization).
  • Sub-pages thi pillar ne link bhuli javu.
