Indexing Check (GSC Page Indexing)

Page Google na index ma nathi to rank thavano j nathi - content game etlo saro hoy. Etle SEO ma pehlo sawal hamesha: "Aa page index chhe ke nahi, ane nathi to kem?" (Added point - juna notebook ma nahotu.)

Kevi rite check karvu

  1. GSC → Indexing → Pages: Indexed vs Not indexed count juvo. Trend achanak niche jay to red flag.
  2. Not indexed reasons vanchho: dar reason no matlab alag chhe, badha "problem" nathi.
  3. URL Inspection: important page nu URL nakho → "URL is on Google" chhe ke nahi, user-declared vs Google-selected canonical juvo.
  4. Live test: page render thay chhe, robots/noindex block nathi te confirm karo.

Common reasons ane su karvu

  • Crawled - currently not indexed: Google e crawl karyu pan hamna index nathi karyu (mostly quality, duplicate ke ochi demand karan) - content improve karo, internal links vadharo, duplicate hoy to merge karo.
  • Discovered - currently not indexed: Google e crawl j nathi karyu - internal links, sitemap ane site quality check karo.
  • Duplicate without user-selected canonical: canonical tag set karo (Technical point 02 juvo).
  • Alternate page with proper canonical tag: mostly normal chhe (filters, variants) - kai karvanu nathi.
  • Excluded by noindex / Blocked by robots.txt: intentional chhe ke bhool thi? Money page hoy to tarat fix.
  • Not found (404) / Soft 404: Technical point 03 juvo.

Senior ni soch

Badha pages index karvana nathi hota. Filter, tag, cart, thin pages index na thay te saru chhe. Focus: money pages (category, product, service, top blogs) index hova joiye — koi exclusion hoy to reason check karo.

Checklist

  • Top 20 money pages URL Inspection thi indexed confirmed
  • Not indexed reasons ni sheet: karan | URL count | iradapurvak? | shu karvu
  • Monthly indexed pages trend note thay chhe

Added 11 Nov 2026 — indexing speed na 2026 facts (research)

  • IndexNow: Bing, Yandex, Seznam, Naver, Amazon product search vanche — GOOGLE VAANTO J NATHI (Google e 2022 ma test kari ne adopt na karyu). Free; Cloudflare/Shopify/Wix/RankMath ma ek toggle. Enable karo, pan Google mate asar 0.

  • Google Indexing API: faqt JobPosting ke livestream (BroadcastEvent) pages mate — general pages par scope violation (quota revoke risk). 200 requests/day. Ecommerce/blog pages mate use nahi.

  • Google mate real channels: XML sitemap (primary), homepage/crawled pages thi internal links, URL Inspection → Request Indexing (key pages only, daily quota).

  • Realistic indexing time: established site = kalak thi 2-3 divas; navi site = divas thi 2-6 week. Google kyarey crawl/index ni guarantee nahi aapto (CONFIRMED: crawling-indexing FAQ).

  • Detail + fast ranking playbook: 03 → 10 Fast Ranking Strategy (11 Nov 2026).

Canonical, Duplicate Content & Noindex

Ek j content ghana URLs par khule (www/non-www, http/https, ?ref=, filters, variants) to Google ne pasand karvu pade ke kayu URL batavvu, ane links/signals vahenchai shake. Canonical tag Google ne kahe chhe: "aa content nu main URL aa chhe".

Duplicate kya thi aave

  • http vs https, www vs non-www, trailing slash / vs no slash
  • Tracking parameters (?utm=, ?ref=), sort/filter parameters
  • Shopify: /collections/x/products/y ane /products/y - same product be URL
  • Print pages, tag pages, same description vala ghana product pages

Fix kevi rite

  1. Self-canonical: dar indexable page par potana clean URL no canonical.
  2. Duplicate versions: main URL taraf canonical (ya 301 jo duplicate URL ni jarur j nathi).
  3. Site-wide 301: http → https ane www/non-www mathi ek j version.
  4. Noindex: je page users mate jaruri pan search mate nahi (thank-you, internal search, login) - meta robots noindex.
  5. Internal links: hamesha canonical URL ne j link karo - nahi to Google ne mixed signal male.

Common mistakes (aa bhool na karo)

  • Noindex + robots.txt block sathe: robots block hoy to Google noindex tag vanchi j na shake
  • Canonical ek page par ane sitemap/internal links bija URL par - conflicting signals
  • Badha pages no canonical homepage par - pages index mathi nikli jay

Note: canonical ek hint chhe, order nahi (CONFIRMED - Google docs). Signals consistent hoy to j Google follow kare.

Checklist

  • Ek j preferred domain version (https + www ya non-www), baki 301
  • Indexable pages par self-canonical
  • Sitemap
  • internal links + canonical - teno match
  • Noindex pages robots.txt ma blocked nathi

Redirects, 404 & Broken Links

URL badlay, page delete thay, product band thay - dar vakhte saacho status code jaruri chhe. Galat handling = backlinks waste, users frustrated, crawl budget waste.

Status codes simple bhasha ma

  • 301: kayam mate move thayu - page ni value nava URL ne pass thay. Slug change, domain change, pages merge mate.
  • 302: temporary move (sale page, A/B test). Lambo time 302 rakhvu nahi.
  • 404: page nathi. Normal chhe - badha 404 problem nathi.
  • 410: page kayam mate gayu - Google 404 jevu j treat kare (farak bahu nano).
  • Soft 404: page "nathi" kahe pan status 200 aape, ke badha deleted pages homepage par redirect - Google ene soft 404 gane.

Kevi rite check karvu

  1. Screaming Frog crawl → Response Codes → 3xx, 4xx filter.
  2. GSC → Pages → Not found (404) ane Soft 404 lists.
  3. Redirect chains: A → B → C hoy to A → C direct karo (max 1 hop).
  4. Redirect loop: A → B → A - page khule j nahi, tarat fix.

Nirnay no niyam

  • 404 page par backlinks ke traffic hoy → nearest relevant page par 301
  • Koi value nathi ane replacement nathi → 404/410 rehva do
  • Internal broken link → link j update karo (redirect par aadhar na rakho)

Checklist

  • Monthly crawl: 0 internal broken links
  • Koi redirect chain ke loop nathi
  • Backlink vala 404 pages ne 301 aapela
  • Search ane popular links sathe custom 404 page

Schema Markup (Structured Data)

Schema = code (JSON-LD format) je Google ane AI systems ne page vishe clear facts aape: aa product chhe, price aatlo, brand aa, business kya chhe. Schema direct ranking boost nathi aapto (CONFIRMED), pan rich results (stars, price) ane machine understanding mate useful chhe.

Website type pramane jaruri schema

  • Badhi sites: Organization (logo, socials, contact), WebSite, BreadcrumbList
  • Local business: LocalBusiness (NAP, hours, geo) - GBP sathe exact match
  • Ecommerce: Product
  • Offer (price, availability, currency), review/rating fakt jo real reviews page par visible hoy
  • Blog: Article/BlogPosting (author, datePublished, dateModified)

Important 2026 update

Google e 7 May 2026 thi FAQ rich results Search ma batavvana band karya chhe (CONFIRMED - Google Search Central). FAQ section page par users ane AEO mate hju useful chhe, pan FAQ schema thi have rich result nahi male. Pehla HowTo (2023) ane bija ghana types pan retire thaya chhe - navo schema add karta pehla Google docs ma type supported chhe ke nahi check karo.

Steps

  1. Page type pramane schema type select karo.
  2. Implement: WordPress ma RankMath/Yoast, Shopify ma theme ma default Product schema hoy - check karo, jarur hoy to app/JSON-LD.
  3. Validate: Rich Results Test (Google) + validator.schema.org.
  4. Monitor: GSC → Enhancements/Shopping reports ma errors.

Common mistakes (aa bhool na karo)

  • Page par na dekhaye tevi info schema ma (fake rating) - manual action risk
  • Schema price ane page price alag
  • Duplicate schema - theme + plugin banne add kare

Checklist

  • Organization
  • Breadcrumb site-wide
  • Product/Article/LocalBusiness page type pramane
  • Rich Results Test pass, GSC ma errors 0

Added 8 Nov 2026 — FAQ schema final status

  • June 2026 ma Google e FAQ rich result report (GSC) ane Rich Results Test mathi FAQ support pan kadhya — documentation pan remove thayu. [CONFIRMED — Google Search Central]
  • Juno FAQ schema delete karvani jarur nathi — Google pramane unused structured data 'does not cause problems'. Pan navi pages ma FAQ schema banavva time na ghasvo; FAQ section users/AEO mate content tarike j rakho.

Image SEO & Alt Text

Images speed na sauthi common karano ma ek ane Google Images traffic no source - banne. Ecommerce ma product images j sales kare chhe.

Rules (niyamo)

  1. File name: upload pehla rename - IMG_4521.jpg nahi, eggless-chocolate-cake.webp.
  2. Alt text: image ma su chhe te 5-15 words ma describe karo. Keyword naturally aave to saru, stuffing nahi. Decorative images mate alt empty.
  3. Format: WebP (ya AVIF), compress karelu. Product image 100-200 KB target.
  4. Size: display size jetli j image - 4000px image 400px box ma nahi.
  5. Width/height attributes: layout shift (CLS) avoid karva.
  6. Lazy load: fold ni niche ni images lazy. Page ni main (LCP) image lazy nahi.

Ecommerce extra (vadhu)

  • Har product ni unique real photos - manufacturer ni same images badha sellers pase hoy
  • Alag-alag angles + use-case photo + size reference
  • Variant images alag (color pramane)

Kevi rite check karvu

  • Screaming Frog → Images → Missing alt text, over 100 KB
  • PageSpeed Insights → "Properly size images", "Serve images in next-gen formats"

Checklist

  • Content images ma Missing alt text 0
  • Varnanatmak file names
  • WebP
  • compressed, LCP image lazy nathi

Technical SEO Audit (Screaming Frog Crawl)

6 Month Plan na Month 1 ma "full audit" lakhel chhe - aa doc te audit kevi rite karvo te batave. Audit = list of issues nahi, priority sathe action plan.

Steps

  1. Crawl: Screaming Frog (free 500 URLs) ma domain nakho. Mode: Spider.
  2. Response codes: 3xx, 4xx, 5xx ni list (Technical point 03).
  3. Indexability: noindex, canonicalised, blocked pages - intentional chhe? (Technical point 01, 02).
  4. Page titles + meta: missing, duplicate, limit karta vadhare lamba.
  5. H1: missing, ek karta vadhare, duplicate.
  6. Images: alt text missing, size moto.
  7. Crawl depth: money pages 3 clicks thi vadhare deep na hova joiye.
  8. GSC data sathe match: Pages report, Core Web Vitals, manual actions, security issues.

Priority kevi rite nakki karvi

  • Critical: site/money pages index nathi, noindex/robots bhool, site-wide redirect issue - tarat
  • High: money pages par duplicate/canonical issue, broken internal links, slow mobile
  • Medium: meta missing, alt text missing, redirect chains
  • Low: cosmetic (title thodu lambu)

Rule: "Ketla URLs affected" x "te pages ni business value" = priority. 500 blog tags par missing meta < 5 product pages noindex.

Output

  • Sheet: Issue | Example URLs | Count | Impact | Effort | Priority | Owner | Status

Checklist

  • Full crawl thai gayu + GSC data sathe cross-check karyu
  • Issues priority sathe listed
  • Critical issues 1 week ma fixed

Website Redesign & Migration SEO

Navu design, navu platform (WordPress → Shopify) ke navu domain - aa SEO nu sauthi risky kaam chhe. Redirects bhuli gaya to mahinao ni ranking ek divas ma jay. Design & Web Development section sathe aa follow karvu jaruri.

Launch pehla

  1. Old site no full crawl + GSC top pages + backlink vala pages export.
  2. Redirect map: old URL | new URL - dar important URL 1:1 relevant page par 301. Badhu homepage par redirect nahi.
  3. Titles, meta, H1, content ane internal links navi site ma carry karo - kharab design change ok, content loss nahi.
  4. Staging site noindex/password protected - pan launch time te hatavvu yaad rakho.

Launch divas

  • robots.txt ma Disallow: / nathi te check
  • Noindex tags remove karo
  • Redirect map test karo (Screaming Frog list mode)
  • Navu sitemap GSC + Bing ma submit; domain change hoy to GSC Change of Address
  • GA4/GTM tracking live chhe te confirm

Launch pachhi (6-8 week)

  • Dar week GSC: 404, indexing drop, top queries ni position
  • Thodo fluctuation 2–6 week normal; pan motu drop (20%+) ke 404 vadhe to tarat redirects/indexing check - raah na juo
  • Redirects ochama ochu 1 varas rakho

Checklist

  • Redirect map 100% important URLs cover kare
  • Launch divas na checks thai gaya
  • Before/after traffic compare sheet taiyar chhe

Crawl budget & JS

1. Crawl budget kyare jovo

  • Site ma ghana hajar URLs (filters, tags, programmatic pages) hoy.
  • GSC → Settings → Crawl stats: requests, response codes, avg response time.
  • "Discovered
  • currently not indexed" ghana hoy.

2. Waste ghatadvo

  1. Parameter/filter URLs control (canonical, noindex, robots - 08/02, 08/03).
  2. Redirect chains ane 404 ghatadvo (08/03).
  3. Sitemap ma fakat indexable, 200-status, canonical URLs.
  4. Server speed (TTFB) saru - slow server = Google ochhu crawl kare.
  5. Strong internal links important pages ne (05/03).

3. Log files (advanced, optional)

  • Server log mathi Googlebot hits joi shakay: kaya URLs crawl thay, kaya nahi.
  • Tool: Screaming Frog Log File Analyser (ke hosting logs). Googlebot verify karo (fake bots hoy).
  • Important page Googlebot ne dekhatu nathi to internal link / sitemap sudharo.

4. JavaScript SEO

  1. Rule: important content + links normal HTML ma hova joiye (anchor tag with href).
  2. Test: GSC URL Inspection → View tested page → Screenshot/HTML. Content dekhay chhe?
  3. View-source vs rendered HTML compare. Content fakat JS thi aave to risk.
  4. Best: server-side rendering ya static HTML for money pages.
  5. Lazy-load images ma above-the-fold image lazy na karo.
  6. Click par j khulta tabs/accordion content ne Google read kare, pan fakat button click thi load thay (API call) to nahi.

Checklist

  • Crawl stats joyu, 5xx nathi.
  • Important page rendered HTML ma content + links chhe.
  • Sitemap clean.

International & hreflang

1. Structure pasand karo

OptionExampleKyare
Same page, ek English/Content same, fakat price/shipping notes alag
Subfolder/us/ , /uk/Best for most (ek domain ni authority)
ccTLD.co.ukStrong local brand, alag budget

2. hreflang (jo be ke vadhu versions hoy)

  1. Darek version page par badha j versions ni hreflang tag (potani sahit - self reference).
  2. Codes: en-US, en-GB, x-default (fallback).
  3. Return links jaruri: US page UK ne point kare to UK page US ne point kare.
  4. Absolute URLs, canonical same page par self.
  5. Implement: HTML head, ke sitemap ma. Ek j method rakho.

3. Content localisation

  • UK spelling (colour, jewellery) vs US (color, jewelry), UK vs US keywords alag check karo (Semrush ma database US ane UK).
  • Currency, shipping time, returns, VAT/tax notes, size units.
  • Pure copy-paste duplicate nahi - thodu localise.

4. Measure

  • GSC → Performance → Country filter (United States / United Kingdom).
  • GA4 ma country wise sessions + key events.

Mistakes

  • Automatic IP redirect (Googlebot ne block thai jay) - bhale suggestion banner aapo.
  • hreflang return link na hovi.
