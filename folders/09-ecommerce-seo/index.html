Step 66 / 111

Category & Collection Page SEO

Ecommerce ma sauthi vadhare buying keywords ("kids makeup kit", "leather belts for men") category/collection pages par rank kare chhe, product pages par nahi. Etle category page = ecommerce nu main money page.

Optimize kevi rite

  1. Keyword: category ne transactional keyword map karo (Keyword Mapping doc juvo). 1 keyword = 1 collection.
  2. Title + H1: "Kids Makeup Kits" jevu clear, generic "Shop All" nahi.
  3. Intro text: grid ni upar 1-3 line short intro (user mate); vadhare helpful content (buying guide, FAQ) grid ni niche.
  4. Product grid: best sellers/in-stock pehla - out-of-stock products last ma.
  5. Internal links: sub-collections, related collections ane 2-3 related blogs ne link.
  6. Breadcrumbs: Home > Category > Sub-category (BreadcrumbList schema sathe).

Shopify mate khas

  • Collection description theme ma visible chhe te check karo - ghana themes ma hidden hoy
  • Automated collections ma pan manual SEO title + meta set karo
  • Tags/filters thi bani nava URLs index na thay (Ecommerce point 03)

Common mistakes (aa bhool na karo)

  • Be collections ma same products + same keyword = cannibalization
  • Empty ke 1-2 product vali collection index ma - thin page
  • Blog thi product par link aapo pan collection par nahi

Checklist

  • Har collection: alag title, H1, meta, shuruaat nu text
  • Collection-keyword mapping sheet ma
  • Blogs → collections na internal links active chhe

Step 67 / 111

Product Page SEO

Product page long-tail ane brand/model keywords par rank kare chhe ane conversion nu last step chhe. Kharab product page = traffic aave pan sale nahi.

Must-have elements (jaruri vastu-o)

  1. Title: Product name + main attribute ("Organic Kids Lip Balm - Strawberry, 4g"). Brand end ma.
  2. Unique description: manufacturer copy nahi - benefits, use-case, who it's for, ingredients/material, size.
  3. Images: multiple, real, alt text sathe (Image SEO doc).
  4. Price, stock, delivery time, return policy - fold ni upar ke najik.
  5. Reviews: real customer reviews page par visible.
  6. Product schema: name, image, price, currency, availability, brand (Schema doc).
  7. Related products + parent collection ni link.

Merchant listings (free)

Google Merchant Center ma products add karo to Shopping tab ane free listings ma batay - organic product visibility mate. Shopify ma Google & YouTube app thi connect thay. Price/stock site ane feed ma same hova joiye.

Common mistakes (aa bhool na karo)

  • 100 products ni same description (duplicate content)
  • Description fakt image ma - Google text vanchi na shake
  • Schema ma price/stock page thi alag

Checklist

  • Top 20 sauthi vadhu vechata products: alag description
  • Product schema valid chhe (Rich Results Test)
  • Merchant Center connected chhe, feed errors 0

Step 68 / 111

Filters, Variants & Duplicate Product URLs

Ecommerce sites par filters (color, size, price, sort) hajaro URLs banave chhe. Aa badha Google crawl/index kare to crawl budget waste thay ane index ma thin duplicate pages bharay (index bloat).

Problem kevi rite olkhvo

  • GSC → Pages: indexed count products+collections thi ghanu vadhare
  • site:domain.com inurl:filter ke ?sort_by search
  • Screaming Frog ma parameter URLs ni count

Decision (nirnay)

  1. Search demand vala filter ("black leather belt" - real volume) → alag optimized collection page banavo, filter URL nahi.
  2. Baki filters/sort → canonical main collection par, internal linking ma use na karo.
  3. Crawl waste motu hoy → robots.txt thi parameter patterns block (Shopify ma robots.txt.liquid). Pan dhyan: already indexed URLs pehla canonical/noindex thi nikalo, pachhi block.

Shopify duplicate product URLs

  • /collections/x/products/y ane /products/y - Shopify canonical /products/y par set kare chhe
  • Pan theme collection page parthi /collections/.../products/... link kare to Google ne mixed signal - theme ma product links direct /products/ par karo
  • Variants (?variant=123) canonical main product par - alag page fakt jo variant nu potanu search demand hoy

Checklist

  • Indexed filter/parameter URLs ni count track
  • High-demand filters mate dedicated collections
  • Theme product links /products/ format ma

Step 69 / 111

Out-of-Stock & Discontinued Products

Stock khatam thay tyare page delete karvu sauthi common bhool chhe - ranking, backlinks ane reviews badhu jay. Temporary ane permanent case alag handle karo.

Temporary out-of-stock

  1. Page live rakho, index ma rakho.
  2. "Back in stock soon" + expected date + notify-me option.
  3. Similar in-stock products page par batavo.
  4. Availability update: site schema ma https://schema.org/OutOfStock ane Merchant feed ma out_of_stock (banne same hova joiye).
  5. Collection ma product niche khaso.

Permanently discontinued

  • Navu version/replacement chhe → 301 replacement product par
  • Replacement nathi pan close category chhe ane page par traffic/backlinks chhe → 301 relevant collection par
  • Koi value nathi → 404/410
  • Badha discontinued products homepage par 301 nahi - Google ene soft 404 gane

Seasonal products

Diwali/Christmas jeva products na URLs varas-varas same rakho (date vagar slug) - juni ranking aavta varase kaam aave.

Checklist

  • Out-of-stock policy written ane team ne khabar
  • Discontinued list monthly review + redirects
  • Schema/feed availability accurate

Step 70 / 111

Merchant Center

Steps

  1. merchants.google.com → account banavo, website claim + verify.
  2. Policy pages ready: shipping, returns, contact, privacy (05 On-Page / 05).
  3. Product feed: Shopify/WooCommerce app ke Google Sheet feed. Fields: id, title, description, link, image_link, price, availability, brand, gtin/mpn (jo hoy), condition.
  4. Product page par Product schema (price + availability) feed sathe match thavu joiye (08/04).
  5. Diagnostics ma errors ane warnings fix karo (Merchant Center ma "Needs attention").
  6. Free listings (Surfaces across Google) ON.

Rules

  • Price ane stock site par ane feed ma same (09/04 out-of-stock).
  • Image clean, white background, product clear, koi watermark ke promo text nahi.
  • Title ma brand + product + key attribute (color, size).

Monthly check

  • Disapproved products 0 ke ochha. GSC Merchant listings report joyu.

Step 71 / 111

Etsy & marketplaces

1. Etsy listing SEO

  1. Keyword: buyer je words search kare. Etsy search bar suggestions, Alura/eRank jevu tool, Google Trends.
  2. Title: sauthi important keyword pehla; natural, stuffing nahi (140 char limit).
  3. Tags: badha 13 vapro, long-tail phrases (single words nahi).
  4. Attributes
  • categories bharo (occasion, color, style) - Etsy filters ma aave.
  1. First photo + 10 photos, video; thumbnail clear. Photo = click rate.
  2. Description: first 1-2 lines ma keywords + value; FAQ, delivery (digital download), file format.
  3. Reviews
  • fast response; shop policies, about section, shop announcement.

2. Own store sathe jodvu

  • Same product ni description Etsy ane website par alag shabdo ma (duplicate avoid - [LIKELY] precaution).
  • Website par product page ma "Buy on Etsy" button (GA4 event click_buy_etsy
  • 07 Setup / 07).
  • Etsy shop ma website link jya policy allow kare; Etsy rules vanchi lo.
  • Brand name, logo, shop name badhe same (06 Off-Page / 08 Brand).

3. Amazon

  • Title, bullets, backend keywords, A+ content; keyword research Amazon search bar thi.
  • Website ne Amazon par traffic mokalva ma Amazon rules check karo (link policy).

4. Weekly check (20 min)

  • Etsy Stats: visits, views, favourites, conversion. Low views listing → title/tags/photo badlo.
  • Ek vakhat ma ek j change, date note karo (4-6 week result).
