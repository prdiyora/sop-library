Step 100 / 111

Site Architecture — NAVI Website (New Site) — 11 Nov 2026

Universal blueprint: koi pan niche, ecommerce, lead gen, blog ke service site. Sources: Google Search Central, Search Engine Land site architecture guide (2025-26), HubSpot silo guide. Freshness: 11 Nov 2026.

Ek line ma: Homepage → Category/Hub pages → Sub-pages ane blogs — darek page homepage thi 3 clicks ni andar. Paisa kamavta pages (money pages) 1–2 clicks ma. Aa j architecture 1 site hoy ke 100 sites — same rehse.

1. Architecture model pasand karo (99% sites mate same)

ModelShu chheKyare vaparvu
Hierarchical (tree)Homepage → categories → sub-pages99% sites — service, ecommerce nani-mid, blog, lead gen. Aa j default.
Hub-and-spoke (topic cluster)Pillar page + cluster blogs je pillar par link kareBlog/information section mate — hierarchical ni andar j aave
DatabaseTemplate + data thi pages bane (Amazon style)Moti ecommerce ke programmatic SEO (03 → 12 Programmatic SEO)
Matrix / SequentialMulti-path ke step-by-stepSEO mate avoid — crawler confuse thay

2. Universal Page Map (koi pan niche)

AA structure badha projects ma same — niche pramane fakta names badlay:

  • Homepage — brand + main category links + USP (money pages par direct link)
  • Hub / Category pages (3–7) — ecommerce ma collection pages, service ma "Services", blog ma topic pillars. Head keywords ahi target thay.
  • Sub-pages — products / individual services / city pages. Long-tail + buyer intent ahi.
  • Blog clusters — dar hub niche 5–20 supporting blogs, badha hub par internal link kare (pillar ↔︎ cluster)
  • Must-have pages — About, Contact, Privacy, Terms, Shipping/Refund (ecommerce) — EEAT mate (05 → 05 Must-Have Pages)

3. Niche pramane page map (3 ready templates)

A. Ecommerce

  • Homepage → Category (collections) → Sub-category → Product
  • Blog: category-specific guides je products par link kare (03 → 07 Ecommerce Blog Workflow)
  • Filters/variants URL rule: canonical to main page (09 → 03)

B. Lead gen / Service business

  • Homepage → Services hub → Ek page per service (buyer intent: "cost", "quote", "near me")
  • Ek page per city/service-area (jyare actual service aapu tya j — doorway pages nahi)
  • Proof pages: case studies, reviews, before/after
  • Detail: 03 → 11 Lead Gen SEO

C. Blog / Content site

  • Homepage → Topic pillars (3–7) → Cluster posts
  • Dar pillar: 1 long pillar post (2000+ words) + 10–30 cluster posts

4. URL & Slug rules

  • Parent-child URLs: /services/seo-audit, /category/product — hierarchy URL ma j dekhay
  • Slug = primary keyword, short, hyphen (05 → 08 Slug = Keyword)
  • Ek keyword-intent = ek URL (golden rule — cannibalization avoid)
  • Breadcrumbs badha deep pages par + BreadcrumbList schema

5. Internal linking map (asli ranking fuel)

  • Dar page par 3–5 contextual internal links (05 → 03)
  • Cluster → pillar par link (pillar ne authority aape); pillar → money page par link (link equity flow)
  • Silo rule: same topic ni andar dense linking; bija topic taraf faqt jaruri hoy tyare — topical authority saaf rahe
  • Orphan page = 0 internal links = kyarey nahi (05 → 06 No Orphan Pages)
  • Navu page publish thay ek homepage ke top hub thi link — jaldi crawl thay (CONFIRMED: Google navi pages links thi shodhe)

6. Depth & crawl rules

  • 3-click rule: koi pan page homepage thi max 3 clicks (LIKELY — industry standard; Google crawl depth ne importance mane)
  • 4+ clicks deep page = Google ochho important mane ane crawl budget waste thay
  • Moti site (1000+ pages) hoy to pan money pages flat rakho

7. Technical foundation (publish pehla)

  • XML sitemap (badha canonical URLs) + GSC ma submit (07 → 01)
  • Robots.txt — admin/cart/thank-you block; sitemap line (05 → 02)
  • Schema: Organization + WebSite sitewide; Product/Service/Article page pramane (08 → 04)
  • GA4
  • GSC + Clarity day 1 thi (07 Setup folder)
  • IndexNow on (Bing/Yandex mate — ek toggle Cloudflare/Shopify/Wix/plugins ma; Google mate asar nahi — 11 Nov update 08 → 01 ma)
  • Mobile-first
  • Core Web Vitals pass (05 → 04)

8. Build order (navi site, week-by-week)

WeekKaam
Week 1Domain (02 → 06), keyword research + Master Keyword Map (02 → 07), competitor pool (02 → 02), page map paper par finalize
Week 2Design setup (14 folder), Homepage + 3–7 hub pages + must-have pages live, GSC/GA4/Clarity setup, sitemap submit
Week 3–4Money pages (products/services) + pehla 5–10 cluster blogs, internal linking, indexing request (key pages only)
Month 2–3Cluster expand, off-page start (06 folder), first monthly report (11 folder)

Common mistakes (aa bhool na karo): homepage par badha pages ni link dump; category vagar products direct; ek j keyword par 2 pages; deep burial (4+ clicks); navi site par day 1 thi 100 thin pages (scaled content abuse risk — CONFIRMED Google spam policy).

9. Checklist — NAVI site architecture finalize karta pehla

  • Page map paper/sheet ma chhe: homepage → hubs → sub-pages → clusters
  • Darek page nu primary keyword Master Keyword Map ma chhe (1 intent = 1 URL)
  • 3-click rule verify karelu (money pages 1–2 clicks)
  • URL parent-child format ma, slug = keyword
  • Internal linking plan: dar cluster post → pillar; pillar → money page
  • Sitemap
  • robots + schema + tracking ready
  • Breadcrumbs on
  • Koi orphan page nahi

Step 101 / 111

Site Architecture — JUNI Website (Old / Existing Site) — 11 Nov 2026

Client ni chalu site ke apani juni site ne restructure karvani SOP. Rule #1: je chalu chhe e todvo nahi — audit pehla, fix priority pramane, URLs fakta jarur hoy to j badalvi. Freshness: 11 Nov 2026.

Ek line ma: Juni site ma architecture fix = audit → map → blocker fixes → depth/structure fix → internal linking → measure. Rankings save karvani = URL changes minimum + 301 redirects jaruri.

1. Golden rules (juni site mate)

  • Ranking aavti URL kyarey bekar ma na badalvi. Slug kharab hoy pan traffic aave chhe to rakhvi — change kari to 301 jaruri.
  • Ek vaar ma ek j change batch karo ane date note karo (Page Audit & Fix log) — nahi to khbar nahi pade su kaam karyu.
  • Change pachhi 4–6 week wait — Google ne recrawl + reassess karva time joiye (CONFIRMED: Google Starter Guide).
  • Backup
  • current rankings no snapshot PEHLA (01 → 00 Onboarding, Phase 1 baseline).

2. Step 1 — Full crawl & current map (day 1–2)

  • Screaming Frog crawl karo (08 → 06) — badha URLs, titles, depth, status codes, canonicals export karo
  • Depth report: kaya pages 3+ clicks deep chhe — list banavo
  • Orphan pages: 0 internal links vala (GSC + crawl compare kari ne shodho)
  • GSC export: kaya pages par impressions/clicks chhe (aa pages = protected, careful)
  • Current structure no tree diagram banavo (paper ke Whimsical ma)

3. Step 2 — Fix order (aa j sequence ma)

#FixSOP referenceKem pehla
1Crawl blockers: noindex, robots block, khotu canonical08 → 01, 08 → 02Aa hoay to baki badhu bekar
2404s, broken links, redirect chains08 → 03Crawl budget + UX leak bandh karo
3Duplicate content / duplicate URLs (filters, variants)08 → 02, 09 → 03Rankings split thay chhe e jodvo
4Thin/duplicate pages: merge, refresh ke remove10 → 03Quality density vadharo
5Depth flattening: deep money pages ne homepage/hub thi link05 → 03, 05 → 06Importance signal + crawl

4. Restructure karvu hoy to (URL changes)

  • Badli URL mate 301 redirect old → new, ek hop ma (chain nahi)
  • Internal links update karo navi URL taraf (redirect par rely na karo)
  • Sitemap update + GSC ma resubmit
  • 2–4 week GSC ma monitor: impressions drop = turant check
  • Moti restructure = full migration SOP follow karo (08 → 07 Website Redesign & Migration)

5. Architecture fix patterns (je sauthi common chhe)

Pattern 1: Flat dump

Badha pages homepage niche direct (50+ links). Fix: 3–7 hub pages banavo, pages hubs niche move karo, homepage par fakta hubs.

Pattern 2: Deep burial

Money pages 4–6 clicks deep. Fix: homepage/hub thi direct link, related-products/posts widgets, footer links (important pages only).

Pattern 3: Orphan blog posts

Blogs publish thay pan kyathi link j nathi. Fix: hub/pillar pages banavo je badha blogs ne list kare + posts ma contextual links.

Pattern 4: Cannibal clusters

Ek j keyword par 3 pages. Fix: Master Keyword Map (02 → 07, section 8) sathe compare → best page rakho, baki 301 ke merge (10 → 03 decision rules).

Pattern 5: Faceted nav bloat (ecommerce)

Filter combinations e 1000s URLs banavi. Fix: canonical/noindex rules (09 → 03), sitemap ma fakta canonical URLs.

6. 30/60/90 day plan (juni site)

PeriodTarget
Day 1–30Crawl + map + blockers/404/duplicates fix + GSC baseline + quick-win titles (03 → 01)
Day 31–60Depth flattening + hub pages + internal linking pass + content refresh top 10 pages (03 → 02)
Day 61–90Cluster expansion + off-page (06) + first full report compare (11) — measure vs baseline

Common mistakes (aa bhool na karo): rankings snapshot vagar changes; badha URLs ek saathe badalvi; redirect chains (A→B→C); redirect kari ne internal links junu j rakhva; 2 week ma result judge kari ne undo kari devu; sitemap update bhuli javu.

7. Checklist — JUNI site architecture fix

  • Full crawl export + baseline snapshot lidhelu chhe
  • Koi noindex/robots/canonical blocker nathi
  • 404
  • broken links 0 (ke known ane redirected)
  • Duplicate URL issues resolved (canonical/301)
  • Money pages 2 clicks ni andar
  • Koi orphan page nathi
  • Dar badlai URL par 301 + internal links updated
  • Sitemap resubmitted, GSC monitor schedule set
  • Dar change nu date log ma
