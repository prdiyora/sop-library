Traffic Drop Diagnosis

Client kahe "traffic ghati gayu" - panic nahi, step-by-step investigation. Pehla confirm karo ke real drop chhe, pachhi kya ane kem.

Step-by-step

  1. Data confirm: GA4 tracking tuti to nathi? GSC ma pan drop chhe? (GA4 drop + GSC stable = mostly tracking/consent issue).
  2. Seasonality: last year same mahina sathe compare.
  3. Kya drop: GSC ma pages, queries, device, country wise compare - site-wide ke amuk pages?
  4. Impressions vs clicks: impressions same pan clicks ghata = CTR issue (SERP change, AI Overviews, title). Banne ghata = ranking/indexing issue ke demand/seasonality ghati (YoY + Google Trends check).
  5. Technical: recent site changes, noindex, robots.txt, redirects, GSC Pages report ma indexed drop.
  6. Google update: Google Search Status Dashboard par te dates ma core/spam update?
  7. Manual actions + Security issues (GSC).
  8. Competitors: SERP ma kon upar aavyu ane temni page tamara thi kem better chhe.

Pattern → sambhavit karan

  • Achanak site-wide 80% drop → technical (noindex/robots/migration) ke manual action
  • Dhime dhime drop amuk pages par → content outdated / competitors better
  • Update date sathe match → quality issue - content ane EEAT improve (quick fix nathi)

Checklist

  • Drop size + date + affected pages document karela chhe
  • Evidence sathe cause hypothesis
  • Client ne clear explanation + action plan

Content Refresh, Merge ya Remove (Decision)

Junu content ignore karvu = slow decline. Dar quarter content audit karo ane dar page mate ek decision lo: Keep, Update, Merge, Remove ke Create new.

Data levo

  • Pages ni list (sitemap/crawl) + GSC clicks/impressions (12 months) + GA4 key events + backlinks

Decision rules (nirnayo na niyamo)

  1. Keep: saru traffic + conversions - fakt monitor.
  2. Update: impressions chhe pan position 5-20 ke traffic ghatyu - content refresh (Strategy point 2).
  3. Merge: 2-3 pages same intent par (cannibalization) - strongest page ma content merge, baki 301.
  4. Remove: no traffic, no links, no business value, outdated - 404/410 (ya relevant hoy to 301).
  5. Create new: navu intent je koi page cover nathi kartu.

Cannibalization kevi rite olkhvo

  • GSC → query select → Pages tab: same query par 2+ pages alternately rank thay
  • Fakt be pages dekhay etle cannibalization nathi - intent same hoy ane banne weak hoy tyare j problem

Common mistakes (aa bhool na karo)

  • Fakt word count vadharvu = refresh nathi; information gain (navu data, example, experience) add karo
  • Date badli ne kai change nahi - misleading
  • Traffic vagar pan conversion vala pages delete karva

Checklist

  • Dar quarter ni content audit sheet: URL | metrics | nirnay | puru
  • Merged pages par 301 + internal links updated

Core Update Playbook

Steps

  1. Update nu status joyu: Google Search Status Dashboard (status.search.google.com). Update chalu hoy tyare changes na karo; complete thay pachhi data compare.
  2. Compare window: update shuru thaya pehla ni 1-2 week vs update complete thaya pachhi ni 1-2 week (GSC, same weekdays).
  3. Real drop che? GA4 tracking, seasonality, site issues (indexing, robots, redirects) pehla rule out karo (10/02 Traffic Drop Diagnosis).
  4. Kya drop: kaya pages, queries, country, device. Site-wide ke amuk section?
  5. Quality audit: drop vala pages ne top ranking competitors sathe compare - intent, depth, EEAT, originality, user experience (05/01, 05/11).
  6. Fix plan: thin/duplicate pages merge ke improve (10/03), real expertise add, ads/popups ochha, internal links.
  7. Manual action? GSC → Security & Manual actions check. Hoy to alag process (fix + reconsideration request).
  8. Wait: improvements nu asar ghanu vakhat laage; next core update sudhi pan. Result 4-6 week thi vadhu nu ummid rakho.

Client ne kevi rite kehvu

  • Data sathe: "Update ma aa pages gaya, aa karan lage chhe, aa plan chhe". Guarantee nahi (Google: koi pan #1 guarantee na aape).

SEO Forecasting

Steps

  1. Baseline: gaya 3 mahina na GSC clicks ane GA4 organic sessions, key events. Seasonality mate gaya varas same mahino.
  2. Growth source: (a) Quick wins position 4-20 pages, (b) navi pages (pillar + sub), (c) content improvement, (d) CTR sudharo.
  3. Per source estimate: pages x average impressions x expected CTR (position pramane). Conservative lo.
  4. Range aapo: low / expected / high. Ek number nahi.
  5. Target: navi site pehla 3 mahina ma ochho; 6 mahina pachhi vadhu. Existing site ma +10% to +30% mahine base par situation pramane.
  6. Review: dar mahine actual vs target, kaaran lakho; target adjust dar quarter.

Rules

  • Koi ranking guarantee nahi. Estimate label lagavo.
  • Period
  • source dar number sathe.
