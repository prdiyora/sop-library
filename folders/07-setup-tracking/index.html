Google Search Console Setup

Notebook Setup point 1: "Search console - sitemap submit, robot.txt". GSC = free Google tool je batave ke Google tamari site ne kevi rite jove chhe. SEO nu stethoscope.

Setup na steps

  1. search.google.com/search-console → property add karo (Domain property best - DNS verify)
  2. Sitemap submit: Sitemaps → sitemap.xml URL submit karo → "Success" status check karo
  3. Robots.txt verify: URL Inspection thi key pages crawlable chhe te confirm
  4. Email alerts on rakho (coverage issues, manual actions)

Dar hafta use (10 minutes)

  • Performance: clicks, impressions, CTR, position - trend upar jai rahyo chhe?
  • Pages report: indexed vs not-indexed reasons check karo
  • Queries: new keywords jo tya rank thay chhe - content update opportunities

Dar mahine use

  • Position 4-10 pages identify (Strategy point 1 mate)

  • Position 10-20 pages (Strategy point 2 mate)

  • Core Web Vitals status

  • Coverage errors fix karo

Checklist

  • Domain property verify thayu chhe

  • Sitemap submit thayu + Success status

  • Dar hafta 10-min review ni habit

  • Alerts enable chhe

  • Added 8 Nov 2026 — GSC na 2026 navi features

  • Search Generative AI performance report: AI Overviews ane AI Mode na clicks/impressions alag — 31 Aug 2026 thi badha websites mate. Weekly review ma add karo. [CONFIRMED — Google Search Central blog]

  • Multimodal filter: Search type ma 'multimodal' (Google Lens/visual search) — Sept 2026. [CONFIRMED]

  • Platform properties: Instagram, TikTok, X ane YouTube na posts Google Search/Discover/News ma keva perform kare te track — July 2026. Social content vala clients mate. [CONFIRMED]

  • Multi-select filters: countries ane device types ek sathe select thay — Oct/Nov 2026. [CONFIRMED]

GA4 & GTM Setup

Notebook Setup point 2: "GA4 & GTM". GA4 = users su kare chhe te track kare. GTM = tracking codes manage kare without code editing. Banne saathe = complete analytics system.

GA4 setup

  1. analytics.google.com → GA4 property banao → data stream (website)
  2. Measurement ID (G-XXXXXXX) site ma install (GTM thi ke direct)
  3. Enhanced measurement ON: scrolls, outbound clicks, site search, video engagement nu auto-tracking
  4. Key events (conversions) mark karo: form submit, purchase, call click, WhatsApp click
  5. Internal traffic filter (potana visits exclude)

GTM setup

  1. tagmanager.google.com → account + container banao
  2. GTM code site ma install (head + body)
  3. GA4 tag GTM through deploy karo
  4. Custom events: button clicks, form submissions, scroll depth (GA4 Scroll Depth doc juvo)
  5. Preview mode ma test karo, pachhi publish

Reports je matter kare

  • Traffic sources (organic search vadhi rahyu chhe?)
  • Landing pages nu performance
  • Conversion events ni sankhya
  • User flow / engagement

Checklist

  • GA4 installed + enhanced measurement ON

  • 3-5 conversion events mark karela chhe

  • GTM container GA4 tag sathe live chhe

  • Internal traffic filter thayelu chhe

  • Added 8 Nov 2026 — GA4 na 2026 updates

  • Native 'AI Assistants' channel: Default Channel Group ma Google ChatGPT, Gemini, Perplexity vagere nu traffic auto-identify kare — reports ma alag dekhay, manual setup nahi. [CONFIRMED — Google Analytics changelog]

  • Data Manager (beta, Nov 2026): product links, data streams ane first-party data ek jagya e manage; connection health/diagnostics pan. [CONFIRMED]

  • GA4 UI ma native custom dashboards (Aug 2026 rollout) — quick reporting mate; client reporting mate Looker Studio j best rahe. [CONFIRMED]

Microsoft Clarity

Notebook Setup point 4: "Microsoft clarity". Clarity etle free heatmaps + session recordings. GA4 number batave ("kitla aavya"), Clarity behaviour batave ("su karyu ane kya stuck thaya").

Setup

  1. clarity.microsoft.com → project create
  2. Tracking code site ma (GTM thi easiest - Clarity template available). EU/UK visitors hoy to cookie consent (Clarity consent) jaruri; forms ma sensitive data masking on rakho
  3. GA4 sathe connect karo (integration option) - combined insights male

Su jovo (weekly 15 min)

  1. Heatmaps: users kya click kare chhe? Important CTA par clicks chhe? Koi non-clickable element par try kare chhe (design fix)?
  2. Scroll maps: loko kya sudhi scroll kare? Important content fold ni niche chhe?
  3. Session recordings: 5-10 recordings/week juvo - rage clicks, dead clicks, confusion spots shodho
  4. Rage/dead click reports: frustration na signals = UX fix priority

Action na examples

  • Users image par click try kare (link nathi) → image ne clickable banao
  • 80% users 50% scroll pachhi drop → important content upar lao
  • Form ma field par struggle → form simplify karo

Checklist

  • GTM thi Clarity install karyu
  • GA4 connect karyu
  • Weekly recording/heatmap review schedule karyu
  • Top 3 UX fixes identify kari ne action ma mukya

Bing & All Search Engine Submission

Notebook Setup point 5: "Bing submission - all search engine to index site submission". Google 90%+ share dharave, pan Bing free traffic chhe je 15 minute na effort ma male. Bing index Copilot ane amuk AI search tools (ChatGPT search pan, partly) vapre chhe - GEO mate useful [LIKELY].

Bing Webmaster Tools setup karo

  1. bing.com/webmasters → sign up karo
  2. GSC import option use karo - 1 click ma site + sitemaps import (easiest)
  3. Ya manual: site add karo → verify (meta tag/DNS) karo → sitemap submit karo

Bija submissions

  • Yandex Webmaster: jo international/Russia traffic relevant hoy
  • DuckDuckGo: submission nahi - Bing index use kare, Bing ma chho to ethe chho
  • IndexNow: Bing/Yandex ne navu/badlayelu URL turant notify kare (plugin/API) - jaldi discovery, indexing guarantee nahi. Google IndexNow use nathi kartu.

Indexing requests (nava/updated pages)

  • GSC: URL Inspection → Request Indexing (priority pages)
  • Bing: URL submit karo (100/day limit)
  • IndexNow: automatic on publish

Checklist

  • Bing Webmaster verified + sitemap submit karelu chhe

  • IndexNow active (jo possible hoy)

  • New pages mate indexing workflow define karelu chhe

  • Added 11 Nov 2026 — IndexNow nu exact kaam

    • IndexNow ek var on karo (Cloudflare/Shopify/Wix/SEO plugin ma toggle, ke key file site root ma) — pachhi dar navo/updated URL Bing, Yandex, Seznam, Naver ne instant notify thay. 10,000 URLs per POST. Free.
    • Dhyaan: IndexNow Google ma kaam j nahi kartu. Google mate sitemap + Request Indexing j channel chhe.
    • 200/202 response = notification receive thayu — crawl ke indexing ni guarantee nahi. Same URL var-var resubmit na karo (spam filter).

GA4 Scroll Depth Check (Merged from old SEO SOP doc)

Low scroll depth = content improve karvano signal. (Aa doc Priyank na juna SEO SOP folder na doc mathi merged chhe.)

Jaruri vaat

GA4 nu automatic scroll event fakt 90% depth par j fire thay (page na 90% sudhi scroll thay tyare). Etle default GA4 batave kitla users 90% sudhi pohcha - pan 25/50/75% breakdown NATHI male. Finer tracking mate GTM setup jaruri.

Option A: Default 90% check

  1. GA4 → Reports → Engagement → Pages and screens
  2. Explore → free form → "Percent scrolled" dimension add karo (pehla Admin → Custom definitions ma percent_scrolled event-scoped dimension register karo)
  3. Page-wise 90% scrollers no % compare karo

Option B: GTM custom scroll depths (25/50/75/100)

  1. GTM → Trigger → Scroll Depth → vertical 25,50,75,100 percentages
  2. GA4 event tag connect karo (event name: scroll_depth)
  3. Publish → GA4 Explore ma event data available

Samjan

  • <25% scroll = intro weak/wrong audience - headline ane first paragraph fix karo
  • 25-50% drop = middle content boring - subheadings, images, lists add karo
  • 75%+ = content engaging - CTA placement end ma perfect

Checklist

  • GTM scroll depth trigger configure karel chhe
  • Top 10 pages nu scroll data review karyu chhe
  • Low-scroll pages na content improvements list karela chhe
